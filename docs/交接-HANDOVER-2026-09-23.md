### ★ v2.14 要点（专家团全流程重修：调研 → 设计稿两轮确认 → 开发 → QA）

- **用户位置（双通道）**：GPS（`useUserFix`：watchPosition → WGS84→GCJ-02 → 投影；候车 15s/乘车 30s 节流）
  判「人在哪」；官方车辆判「车到哪」（12s 轮询，**GPS 绝不参与站序进度**）；
- **全自动上车**：R1（车辆停靠/刚离上车站）或 R2（GPS 45s 窗口：投影 ≤80m＋位移 ≥150m＋速度 8–80km/h）
  命中即自动切换（**无确认条**）；轻轨段 R2 收紧档（≤60m/≥12km/h/≥3 采样）；切换配轻反馈 toast；
- **安全网**：A1「疑似未上车」/A2「疑似已下车」检出 → 中性提示 + 纠错入口（我没上车/不是这辆/我已下车）→
  可回退不丢方案；冷却 20s；手动通道常备（`board()` 无候选车时=不切换+提示，与 v2.13 行为一致）；
- **站条四态（`NavStrip`）**：已过=**灰**（含对勾）/ 当前·下一站=青花蓝加粗 / 下车站=**副主题绿**（站名）/ 到站=砖红脉动；
  「您在这里」**骑线节点**（纵条不断线；锚点 atIdx 优先）；
- **地图**：双标记（车辆图标=车 z130；**蓝点**=人 z128，`UserDotLayer`）；已驶过=**灰实线**（z74）；
  非乘车区间=**灰虚线**（z68，AMap `strokeStyle:"dashed"`）；取景**指令化**（`useNavFrame`：拖动中不动，落定后仅被遮挡时微调）；
- **折叠区「本站台其他线路」**：**线路为父、方案为子**（树形缩进）；消费 `switch-plans` 的 `plans[].card` +
  **`siblings`**（top-3 走法）；组内 `totalMin` 升序、组间按组内最快；「切换路线」同屏替换进新方案「等车」态、旧弹窗关闭；
- **全屏化**：导航中 `body[data-nav="riding"]`（隐藏底导）+ 吸底操作条（安全区）+ 面板收敛；
- **轻轨段全自动**：`lib/nav/lrt-progress.ts` GPS 投影推算推进（单帧最多 1 站 / 连续 2 帧一致 / hysteresis / 冻结不跳）；
- **后端字段级（0 新端点）**：`/api/station/eta` + **`serverNowMs`**（缓存分支用当前时刻覆盖）；
  `/api/nav/switch-plans` + **`plans[].siblings`**（top-K=3、去重键 `chainRoutes.join(">")+"@"+alightMain`、
  逻辑抽 `lib/nav/switch-plans-shared.ts` + `npm run test:siblings` 17 断言）；
- **其他**：下车横幅（soon=警告色 / now=砖红脉动；绿只标记下车站名；震动禁声音）；StationCard 读秒对时 + 归零即拉 + 护栏 1.5s；
  文案去 AI 化（含 `/recommend` 空态）；排版单行完整（nowrap/禁 ellipsis）；`RouteDetailBody` 已删除（由 `NavDetailBody` 取代）。
