### ★ v2.13.0 要点（12 项交付）

- **导航追踪（核心）**：`lib/nav/track.ts`（引擎纯函数）+ `useRideTracking`（状态机：off → boarding → riding → done；
  车牌锁定〔停靠本上车站 > 刚离站 > 最近〕· 12s 轮询 `/api/route-vehicles` · 挂靠站-区间推进 · 坐标投影切割

- **下车提醒**：下一站=下车站 ⇒ 横幅 + `navigator.vibrate`（iOS 浏览器无震动 → 仅横幅，如实）；到站二次提醒；
- **可切换方案**：**新端点 `POST /api/nav/switch-plans`**（零高德调用 · 20s 内存缓存 · 软降级不 500）——
  从**第一程上车站**出发枚举「其他线路（含换乘 ≤1 + 末段步行）也能到目的地」的方案并直接建模成**完整卡片**；

- **「其他线路」根因修正**：`foldDataOfCard` 由「末程下车站」改为「**第一程上车站**」（用户口径）；
- **轻轨读秒**：`/api/station/eta` 下发 **`depMs` 绝对发车时刻**（含实测偏差）+ **秒级选班** + 轻轨站**跳过 20s 缓存**；

## 三、关键基建（接手必知）

### 3.1 数据库表

| 表 | 用途 | 状态 |
|---|---|---|
| `route_shapes` | 线路走向（离线抓高德；polyline 是 **GCJ-02**） | bus 90 线 / lrt 3 线 |
| `lrt_route_params` | 轻轨线路级参数（石排湾 `-5s`/100s · 横琴 `+40s`/135s） | 2 行种子 |

### 3.2 接口

| 接口 | 用途 |
|---|---|
| `GET /api/route-lines` · `/api/route-shapes?code=` · `/api/route-vehicles?code=&dir=` | 线路清单 / 走向 / 实时车辆（车牌 / 坐标 / 区间，GCJ-02） |
| `GET /api/stations?include=lrt&v=N` | 站点（带 `color/color2/lines/colors`；改响应结构要 +v 破缓存） |
| `GET /api/station/eta?code=` | 报站（轻轨 `etaSec`/`biasSec` + **`depMs` 绝对发车时刻**，偏差已应用；轻轨站不走缓存） |
| **`POST /api/nav/detail-body`** | 详情弹窗数据（strips + 折叠栏 + legs 几何锚点；不重算 planNav） |
| **`POST /api/nav/switch-plans`** | 🆕「本站台其他线路 · 可切换方案」（零高德 · 20s 缓存 · 软降级；返回完整卡片供直接跳转） |
| `GET /api/nav?...` / `POST /api/fav-routes/plan` | 全量推荐 / 收藏预设链推荐（chain 模式不调高德） |
