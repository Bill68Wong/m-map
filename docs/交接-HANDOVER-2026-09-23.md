## 一、项目速览

- **技术栈**：Next.js 15.5（App Router）+ TypeScript + Vercel + Supabase（PostgreSQL）+ 高德地图 JS API
- **当前版本**：**v3.0.0**（2026-09-25 · 品牌落地 `8626547` · 已上线 · Vercel 远端构建通过）
- **业务覆盖**：全澳 **92 条巴士线 + 3 条轻轨线**（100 条在 `routes` 表）
- **双链路**：`/`（全屏地图 + 三档面板 + **导航界面**：开始导航 → **全自动上车**（R1/R2）→
  站条四态 +「您在这里」骑线节点 + 双标记（车/人）+ 灰实线已驶过 + 下车横幅 →

### 3.1 数据库表

| 表 | 用途 | 状态 |
|---|---|---|
| `route_shapes` | 线路走向（离线抓高德；polyline 是 **GCJ-02**） | bus 90 线 / lrt 3 线（2/21A/59 方向已修正） |

### 3.2 接口

| 接口 | 用途 |
|---|---|
| `GET /api/route-lines` · `/api/route-shapes?code=` · `/api/route-vehicles?code=&dir=` | 线路清单 / 走向 / 实时车辆 |
| `GET /api/stations?include=lrt&v=N` | 站点（改响应结构要 +v 破缓存） |
| `GET /api/station/eta?code=` | 报站（`depMs` 绝对发车时刻 + **`serverNowMs`** 对时基准） |

| `GET /api/nav?...` / `POST /api/fav-routes/plan` | 全量推荐 / 收藏预设链推荐 |
