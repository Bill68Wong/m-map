## 三、关键基建（接手必知）

### 3.1 数据库表

| 表 | 用途 | 状态 |
|---|---|---|
| `route_shapes` | 线路走向（离线抓高德；polyline 是 **GCJ-02**） | bus 90 线 / lrt 3 线 |
| `lrt_route_params` | 轻轨线路级参数（石排湾 `-5s`/100s · 横琴 `+40s`/135s） | 2 行种子 |

### 3.2 接口

| 接口 | 用途 |
|---|---|
| `GET /api/route-lines` · `/api/route-shapes?code=` · `/api/route-vehicles?code=&dir=` | 线路清单 / 走向 / 实时车辆 |
| `GET /api/stations?include=lrt&v=N` | 站点（带 `color/color2`；**改响应结构要 +v 破缓存**） |
| `GET /api/station/eta?code=` | 报站（轻轨 `etaSec`/`biasSec`，偏差已应用） |
| **`POST /api/nav/detail-body`** | 🆕 详情弹窗数据（card → strips + 摺叠栏；不重算 planNav） |
| `GET /api/nav?...` / `POST /api/fav-routes/plan` | 全量推荐 / 收藏预设链推荐（chain 模式不调高德） |

### 3.3 关键组件

| 组件 | 职责 |
|---|---|
| **`RouteResultSheet.tsx`** | 🆕 全屏推荐弹窗（常驻挂载：关闭再开秒显上次结果；换 query 或点刷新才重拉） |
| **`RouteDetailSheet.tsx`** | 🆕 全屏详情弹窗（fetch detail-body；z-80 叠在推荐层上） |
| **`RouteDetailBody.tsx`** | 🆕 详情共享渲染（`/nav/detail` 页面与弹窗共用，防漂移） |
| **`lib/nav/detail-fold.ts`** | 🆕 otherRoutesAt / foldLiveAt / foldDataOfCard（页面与 API 共用） |
| `RouteLinesSheet` / `VehicleMarker` / `VehicleCard` / `RefreshButton` | 选线弹窗 / 车辆图标 / 车辆卡 / 刷新键 |
| `lrt-transfer.ts` | 换乘站切法（只含结构、不含色值） |

⚠️ **弹窗层级全景**：品牌栏 20 / 站点卡 30 / 底栏 30 / 搜索层 60 / 选线层+推荐层 70 / 详情层 80；
弹窗必须挂在 `.nav-map-wrap` **之外**（wrap 是层叠上下文 —— Spec AC-13 教训）。

## 五、🔴 必知铁律（新对话务必先看）

### 5.1 工程铁律

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | **新 API 必须加 `src/middleware.ts` 的 `PUBLIC_PREFIXES`** | fail-closed 默认拒绝；`/api/nav/*` 子路径被前缀自动覆盖 |
| 2 | **改 `.json` 用编辑器工具**，禁 PowerShell `Set-Content` | 会写 BOM ⇒ build 报 `Unexpected token '锘?'` |
| 3 | **`npx` 可能静默失效** ⇒ node 直调 CLI 实体 | 判定：「日志里连 `exit=` 都没有」= 命令没跑 |
| 4 | **发版三绿**：tsc + eslint + build 全 exit 0 | 主人明令 |
| 5 | **effect 依赖与提前 return 必须一起看** | `if (phase!=="ready") return` + 依赖缺 phase = 永不启动（v2.11.0 修复的教训） |
| 6 | **verify 脚本 nth 索引 0-based**；深夜测要挑有车方向 | 组合 8/9 方向相反、深夜只有关闸侧有车 |
| 7 | **mock 数据用服务端真实口径**（route 名是简体 `LRT-石排湾线`） | 繁体会导致秒级正则不匹配的假失败 |
| 8 | **commit message 含 `'` `"` 时用 `git commit -F <file>`** | PowerShell 内联转义失败 |
| 9 | **不动 `.workbuddy/` 下任何内容** | 未纳入 git，删了救不回 |
