**标志的颜色为什么不用 `--accent`**：内联实测踩到过坑 —— `mark-dark.svg` 若写 `var(--accent, #a8c7fa)`，在浅色主题页面里 `--accent` 解析成 `#1b4d8f`，**深底版被染成浅色、整份资产失效**。故拆成两组品牌专用 Token：`--brand-route/--brand-pin/--brand-fg/--brand-muted`（**随主题**切换，见 `tokens-brand.css`）与 `--brand-*-on-dark`（**固定深底**，永远亮色）。效果：`mark.svg` 内联进深色主题会**自动变亮蓝/亮绿**（同一个文件不改图），`mark-dark.svg` 放在任何主题里都保持亮色（用于固定深色底）。

**平台的形状规矩**（这版按规矩分开了，别搞混）：
- **预圆角 20%**：favicon 16/32、PWA `any` 192/512 —— 浏览器与安装面板**不会**再切形。
- **满幅方角**：apple-touch 180、maskable 512 —— 由系统自己切形状。apple-touch 预圆角会被 iOS 二次切角（边缘露白圈）；maskable 预圆角会在安卓遮罩下露出圆角外的透明底。
- **maskable 安全区**：内容压在中央 **80% 安全圆**内（最大对角半径 181px / 可用 205px），任何系统切形都切不到 M 与钉。

**横排 lockup 的字**：上行 `M Map`（`--font-display` Barlow 700 / 30px / `-0.015em`，`textLength="80"` 锁宽 —— 缺字体也不撑破视框）；下行中文名（Noto Sans SC 500 / 15px / `0.02em`）。视框 156×64，右留 10 单位余量。**中文名定名后改 `make-brand.mjs` 的 `cn` 一处重跑即可。**

### B. App 图标底色怎么定？—— 四个候选（用户问题）

同一枚定稿 mark，只换底与配色；每格都有 **512 效果 + 192/32/16 三档缩略 + 对比度实测**（见 `final/preview.html` §B、`screenshots/r5-cand-1..4.png`）。

| # | 底色 | 路线/底 | 钉/底 | 一句话 |
|---|---|---|---|---|
| ① | 白 / 浅底（站牌白 + 描边） | `#1b4d8f` / `#fff` = **8.38:1** | `#0b6e4f` / `#fff` = **6.25:1** | 与 App 内 `.nav-brand` 站牌同源、语言最连贯；但在浅色壁纸/浅色标签条上「没有边」，16px 全靠那圈蓝框撑 |
| **②** | **青花蓝底（推荐）** | `#fff` / `#1b4d8f` = **8.38:1** | `#6dd58c` / `#1b4d8f` = **4.61:1** | 主色即底色，明暗对比全场最高，**双色语义完整保留**；代价是蓝色图标在出行品类里常见，独特性靠 M 字形自己扛 |
| ③ | 澳门绿底 | `#fff` / `#0b6e4f` = 6.25:1 | `#f0b429` / `#0b6e4f` = 3.36:1 | 最在地；但**绿底把绿钉吃掉**，钉必须改成金 → 丢掉「绿＝到达」的语义，双色记忆点被削弱 |
| ④ | 深色底 | `#a8c7fa` / `#111318` = **10.81:1** | `#6dd58c` / `#111318` = **10.22:1** | 与深色 Token 逐一对应、对比最高、深夜场景气质最好；但黑底图标在深色壁纸/Dock 上会糊成方块，作唯一图标太赌 |

**推荐落地策略**：站点只登记 **②**（manifest / apple-touch / favicon 全部指向它）；**①** 用作 App 内品牌位与分享卡（与站牌同源）；**④** 保留为深色模式 PWA 备选，暂不上线。
一句话：**② 是「品牌识别」与「可辨识度」的最优交集，③ 是唯一会因为自身逻辑而死掉的候选**（绿吃绿）。

### C. 中文名提案（7 选 1 + 现名评估）

**约束**：① 面向「澳门通勤 + 全澳导航」，不能把品牌锁死在单一学校/单一人群；② 核心用户是澳科大（MUST）学生 —— **大部分是内地生**，纯粤语词虽有在地感，要计入理解成本；③ 要与「路线 M → 终点钉」的标志、与英文名 M Map 有呼应；④ 2 字优先（好叫、好排、icon 下不挤）。

| 候选 | 类型 | 构思 · 来源 | 读音节奏 · 气质 | 与标志 / 与 M Map | 风险 |
|---|---|---|---|---|---|
| **顺路**（首选） | 意象 · 承诺 | 「路线」+「顺利」压进一个词：地图上是一条路，体感上是「一路顺」 | `shùn lù` 去+去，两拍落地好叫；温润、日常、不炫技 | M 本身就是「一条路」，两站环是节拍，收笔那枚钉＝「顺到了」；M Map 是「图」（系统），顺路是「用」（承诺） | 通用词，检索不占优 → 用「顺路 M Map」组合检索 |
| 到站 | 写实 · 公交原生 | 报站、终点站、到站提醒 —— 公交里最原生的一句话 | `dào zhàn` 去+去，干脆、通知感；朴素准确，最不像「营销起名」 | 钉＝终点＝「到站」，字面同义；两站环就是「站」，标志即名字 | 偏「公交」不偏「导航」，想象空间窄；也像一句提示而非名字 |
| 一路 | 意象 · 一笔到底 | 「整条路线」＋「一路顺风」；正好是 logo 的握笔逻辑 | `yí lù` 阴平+去声，舒展；柔和、耐心、陪伴感 | 标志就是「一笔到底、收笔即钉」；「一路 · M Map」双行很顺 | 易与「一路通/一路发」混；单独出现语义偏虚 |
| 过海 | 在地 · 通勤现实 | 澳门人把「去氹仔/路环」叫过海 —— 每天跨桥通勤就是这个产品 | `guò hǎi` 去+上，先压后扬有画面；极在地、有故事 | 路线出发→跨过去→钉在对岸，与「过桥→到达」完全同构 | 对内地生/游客无直接含义，也不覆盖半岛内短途 |
| 带路 | 拟人 · 本地朋友 | 不是冷冰冰的「导航」，而是「有个人在前面带你走」 | `dài lù` 去+去，动词起头有服务姿态；热情、可靠 | 整条 M 就是「带路的那条线」，钉子落下处就是「带到」 | 「带路」在特定语境有负面联想；略口语 |
| M 到 | 双语口令 · 与 M Map 同源 | 把首字母当名字：M 到了；也可读作极简代号「em 到」 | 单音节字母 + 去声，极短；年轻、利落、有科技感 | M 收笔即到达，钉一落＝「到」，名字即标志的动作；与 M Map 共享 M，母子关系最紧 | 过于极简，语义要靠品牌自己教；中文母语者第一眼可能读不懂 |
| 澳图 | 写实 · 地图原生 | 澳门 + 图（Map）：延续「XX 地图」的品类认知 | `ào tú` 去+阳平，稳，像产品名；正式、可靠、工具感 | 钉在地图上的钉，名字说的就是标志在做的事；「澳图 M Map」中英对读最好记 | 与「奥图」同音易误听误搜；品类词做品牌，差异化不足 |

#### 现名「MUST登校」评估 → **不删除，降级为「场景名」**

**值得保留**：① 精准打中核心用户自我认同（澳科大学生一看就懂）；②「登校」有画面感，比「通勤」有温度；③ M 与 M Map 首字母共用，母子品牌天然成立。

**不能当主名**：

1. **把品牌绑死在两件事上** —— 澳科大（MUST）+ 上学（登校）。产品已扩到「全澳导航 + 通勤 + 实时报站」，非 MUST 用户（其他高校、本地居民、游客）会觉得「这不是给我的」。
2. **不是产品名，是活动名** —— 「英文缩写 + 动作」的构词读起来像迎新活动/班会口号，缺工具类产品的稳感。
3. **中英不对位** —— 英文 M Map 说「地图品类」，中文 MUST登校 说「校园场景」，两套语义各说各话，lockup 里容易打架。
4. **覆盖面越大，获客损耗越大** —— 非科大的澳门通勤者第一眼就被筛掉。

**建议**：主品牌换成面向全澳的 2 字名（**首选「顺路」**，次选「到站」/「M 到」），把「MUST登校」保留为**面向澳科大的活动/落地页副题**（迎新季地推、校园卡片、社团合作）。既保住核心用户的亲切感，又不挡非科大学生的门。

### 反馈 → 对策

### 三个方案（A / B 二选一，C 备选）

## 3. 终点地图钉 · 重做（用户反馈「长歪了」）

### 3.1 旧版为什么歪

线上 `.nav-map__destpin` 用「**圆角方块 + `rotate(-45deg)`**」拼水滴：
1. **整块容器连 `box-shadow` 一起转了 45°** ⇒ 投影斜着走（视觉上就是"歪"的主因）；
2. 白点靠 `top:34%` + 负 `margin` 硬凑圆心，旋转后仍偏。

### 3.2 重做版

直接画一条**对称钉形路径**（圆头 + 两条切线收到尖），**零旋转、零偏移**：
- 白点圆心 = 钉头圆心 `(16,19)`；
- 投影永远朝**正下方**；
- 钉尖固定在 `viewBox` 正底边中点 `(16,40)` ⇒ **锚点 = 坐标点**，不再漂。

几何：钉头圆心 `(16,19) r 9.5`；钉尖 `(16,40)`；切点 `(7.53,23.3)/(24.47,23.3)`；`viewBox 0 0 32 42`。

### 3.3 替换建议（文件:行）

| # | 文件:行 | 现状 | 改为 |
|---|---|---|---|
| ① | `src/app/globals.css:2128-2149` | `.nav-map__destpin { border-radius:50% 50% 50% 0; transform:rotate(-45deg); background:var(--error); ... }` + `::after` 白点 | 整块换成 **SVG 背景**（见 `tokens-delta.css` 尾部「落地补丁」）：<br>`background: url("/pin-destination.svg") center/contain no-repeat;`<br>`filter: drop-shadow(var(--destpin-shadow));`<br>**注意：不要再叠加 `transform: translate(-50%,-100%)`** —— 高德 marker 的 `offset` 已是「自左上角偏移」的锚点约定，再叠 CSS transform 会**双重偏移**（钉尖上移半格）。钉尖对准坐标点由 ③ 的 `offset` 单独完成。（此条依据已于前端落地后更正，实际实现见 `globals.css:2131-2136`） |

## 4. 慢速色（更慢）候选

### 4.1 为什么要换

折叠区路线对比里，「更快」是绿（`--brand-green`），「更慢」现在复用 `--warn #a85e00`。用户要**更"黄"一档**。

两个问题：
1. **语义耦合**：`--warn` 同时被 8+ 处「警告横幅 / 徽标」占用 ⇒ 不擅改 `--warn`，**另开慢速专色**。
2. **既有可访问性缺陷**：`--warn #a85e00` 在次表面 `--surface-2` 上仅 **4.14:1**，**未达 AA**（这是**现状缺陷**，本次顺带修复）。

### 4.2 候选（Token 名 + 色值 + 理由）

| 候选 1 备用（略亮） | — | `#96700a` | `#f0c542` | 更亮但次表面 3.82:1 不达标，**不采用** |
