# ADR-105：本地候选质量闸门「覆盖度」口径修正（防误杀轻轨/等待型方案）

## Status

Proposed（2026-09-26 深夜 · v3.3.0 Phase 1 新增排查产出 · 线上实测支撑，待 team-lead 确认）

## Context

- 现象（用户报告）：导航「**石排灣→科大**」推荐「**步行到協和醫院上车**（氹仔线）」，而正确解应含「**石排灣上车（石排湾线）→ 協和醫院换乘（氹仔线）→ 科大**」。
- 线上实测（显式 OD，GCJ-02）：该 OD `localCandidates=131` 但 **`localKept=0`**（跨 3 次复现稳定）；输出全是 Amap 卡，其中 card = 「walkOut 12.6 → 協和 + 氹仔线」。
  - 分段对拍：石排灣→協和 的**本地卡保留**（`900018 = lrt:石排湾线`）⇒ 石排湾线枚举/实时正常；協和→科大 的氹仔线正常。⇒ **两段各自成立，组合被丢**。
  - Amap 降级态（`amapPlans:0`）该 OD **直接 0 卡** ⇒ 本地兜底全灭。
- 代码事实：
  - 合并闸门 `src/lib/nav/merge-sources.ts#applyLocalGates` 五闸门；**闸门 3 = 覆盖度 ≥0.5**，**仅对本地候选生效**（Amap 候选不过闸门）。
  - 覆盖度 `src/lib/nav/recompute.ts#ourDataCoverage = 我们数据分钟 ÷ 门到门总时长`，分子**只含「乘车段 + 非估算换乘」，不含步行与任何等待**（`totalMin` 含它们）。
  - 本地候选 `suspect` 硬编码 false（`nav-service.ts` L556）⇒ 闸门 5 不适用；降级态无重复 ⇒ 闸门 4a 不适用。
- ⇒ 闸门 3 的**唯一可能**：全轻轨方案「乘车+换乘 ≈11.8min、两次轻轨等待（班次稀疏）>10min」⇒ 覆盖度 ≈0.4 <0.5 ⇒ 被丢；Amap 的同 OD 卡因**不过闸门**而幸存。

## Decision

修正**本地候选质量闸门**中「覆盖度」的口径，避免误杀**轻轨 / 等待型**方案：

1. **口径修正（核心）**：`ourDataCoverage` 的「我们的数据」分子**纳入**：
   - 轻轨段的**等待时间**（由时刻表推导 = 我们的数据，非估算）：`if (r.kind==='lrt') ours += r.minutes + (r.waitMin ?? 0)`；
   - 首末步行中**有实测/几何依据**者（walk level ≤2 视为实测）。
   或等价地：分母改为「**本可由我们数据覆盖的时段**」。
2. **轻轨方案豁免**：**全轻轨**、或「首/末段含轻轨」的本地候选**豁免覆盖度闸门**（LRT 段本就是我们的数据，等待是真实信息）。
3. **观测补齐**：`mergeSources` 的 `dropped`（含 `low_coverage(x)` / `unsolvable_stops` / `duplicate_of_amap` / `suspect`）**并入 `/api/nav` 的 `stats`**（现仅记 Amap 解析丢弃 ⇒ 本类问题长期不可见）。
4. **Amap 降级态保障**：降级时本地兜底**不得**因闸门全灭而空结果（至少出「含轻轨」的可用方案）。

## Considered Options

1. **保持闸门不动，仅调 `minCoverage` 阈值**：治标——0.5 下调会放行更多低质本地卡，副作用不可控。
2. **修正覆盖度口径 + 轻轨豁免 + 观测补齐（采纳）**：直击「分子漏算步行/等待 + 只罚本地」的双重偏差；改动集中（`ourDataCoverage` + `merge-sources` 一处豁免 + stats）。
3. **取消本地闸门**：风险过大（无背书方案全量曝光），否决。

## Consequences

- 正面：轻轨组合（尤其跨线换乘）不再被系统性误杀；Amap 降级时本地兜底可用；诊断可见（stats.dropped）。
- 负面：覆盖度口径放宽后，可能放行少量「等待占比高」的本地卡；由其余闸门（站序可解 / 去重 / suspect）+ 统一排优兜底；上线后以灰度观测。
- 验证（并入 Spec 验收项）：OD「石排灣→科大」**必须**出现「石排湾线→協和换乘氹仔线→科大」候选且 `totalMin` 并列前位；Amap 降级态**不得**空结果；回归「**石排灣→大三巴**」（历史同族：Amap「轻轨+打车」解析）。
- 同族根因：轻轨组合的候选来源脆弱（Amap 不含石排湾线支线 / 乱组合；本地被闸门杀）——本 ADR 解「本地侧」。
