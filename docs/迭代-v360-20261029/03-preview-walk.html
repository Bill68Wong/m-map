地图三种路 · 圆点虚线（SVG 示意 / AMap 参数见文档 §2.3）

donePath · --map-walk-done · w5 · z69 nowPath · --map-walk-ahead · w7 · z73 aheadPath · --map-walk-ahead · w5 · z70

为什么必须是 lineCap:"round"（同一 dasharray 的三种结果）：

实线会被读成「已建成的道路」；butt 线帽下 dash 0.5 几乎不渲染，只剩一排"针脚"，像施工路段；只有 round 线帽会把每个 dash 补成直径 = 线宽的圆点。

05

速度分档 · 六档（新增档 0「大概率赶不上」，仅详情页）

大概率赶不上 全力冲刺有机会赶上 小跑能赶上 正常走能赶上 慢慢走能赶上 爬过去都能赶上
深色模式（反向）： 大概率赶不上 深色 --danger = #ffb4ab（亮红），此时必须配黑字 —— 白字在这个底上只有 1.70:1；黑字 12.37:1。所以 --tier0-fg 深浅两态不能共用同一值。

档 0 是六档中唯一实心底（--danger 实心红 + 白字，6.06:1）。两条通道同向叠加：① 色相单调 —— 档 1 本就是浅红底（--error-container），档 0 用更重的红，不会出现"浅红比档 0 更急"的倒挂；② 实心 vs 浅底 —— 六档里只它一个实心，不看色相也认得出。红的三条形态分工：删除确认 = 描边红 ｜ 到站 = 脉动红 ｜ 档 0 = 实心红块 + 白字，互不混淆。不用绿（绿 = 更快/能赶上）；不加图标（六档形态一致）；不可点（AC-37）；仅详情页渲染，scope="list" 时组件直接不输出。

可点 idle
