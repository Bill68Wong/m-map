## 1. 产品定义

- **一句话**：把「到站之前」与「下车之后」这两段路补上，让 M Map 从「车上的导航」变成「门到门的导航」。
- **目标用户**：澳门日常通勤者与访澳旅客，用手机、边走边看。
- **核心问题**：当前产品只在**上车后**才真正开始导航；用户从家到车站、从车站到目的地这两段，系统只说「步行 6 分钟」，不告诉你怎么走。

## 5. 接口契约（锁定）

### 5.1 新增

| Method | Path | 说明 | 鉴权 | 限流桶 |
|---|---|---|---|---|
| GET | `/api/nav/walk` | 步行分步指引（steps + 折线 + 距离/时长） | 公开 | `walking` |
| GET | `/api/route-stops?code=&dir=` | 线路站序 + 站名 + 坐标 + 代表点 | 公开 | 无（纯 DB，走缓存） |

### 5.2 变更（向后兼容）

| Method | Path | 变更 | 兼容性 |
|---|---|---|---|
| GET | `/api/poi/suggest` | 响应新增**可选**字段 `routes: PoiSearchResult[]`（最多 3 条，`kind="route"`）；`results` 顺序与语义不变 | 旧消费方忽略新字段即可 |

> ⚠️ `PoiKind` 新增 `"route"` 后，`PoiSearchBox.tsx:45` 的 `Record<PoiKind,string>` 会**强制**要求补文案（漏写则 tsc 报错），这是有意的编译期护栏。

### 5.3 下线 / 加固

| 路径 | 处置 | 理由 |
|---|---|---|
| `POST /api/dsat/grab` | **Bearer `GRAB_TOKEN`**，未通过 401 | 全仓唯一无鉴权写接口，拆门即被用来污染采集库 |
| `/api/timer/*`（含 `GET /api/timer/[id]`） | **410 Gone** | id 自增可顺序扫描 = 真实行程泄露 |
| `/api/free/*` | **410 Gone** | 开发期工具，无真实用户写入路径 |
| `/api/fav-routes`（POST/plan/validate） | **保留**（产品功能）：同源 403 + body ≤16KB + `fav` 桶限流 | 现状即公开可写，本轮加护栏不关闭 |
| `/api/dsat/eta`、`/api/station/eta` | 走新增 `dsat` 令牌桶 | 防止拆门后第三方刷 DSAT 配额 |

## 9. 验收标准（68 条 · 摘要）

完整清单见 `01-产品-需求对账与验收标准.md`（AC-01~AC-56 + 12 条细分，共 68 条）。以下为**门禁必过**的 10 条：

| 编号 | 断言 | 可测方式 |
|---|---|---|
| AC-25 | 只由定位触发上车；车辆数据不得单独触发 | 注入 `setGeolocation` 造「车到、人未动」→ 断言仍 `boarding` |
| AC-25a | 定位不可用时显示「自动判定已暂停」+ 手动入口；钩子 `.nav-actions[data-board-detect]=paused` | 拒绝定位权限后断言文案与属性 |
| AC-50 | `POST /api/dsat/grab` 无 Bearer → 401 | curl |
| AC-50b | `/api/timer/*`、`/api/free/*` → 410 | curl 全组 |
| AC-50c | `/api/fav-routes` 跨站来源 → 403；正常同源 → 200 | 改 Origin 头 |
| AC-08 | 从**点开步骤**到步骤可见（不承诺固定秒数） | 手工计时 + 骨架屏出现 |
| AC-08a | 详情体到达即预取首末两段；展开命中 ≤200ms | 网络面板 |
| AC-42 | 全景页每站报站按视口懒加载；顶→底滑 3 次请求计数 ≤30 且不随次数线性增长 | Playwright |
| AC-40 | 线路结果在列表**开头**，带线路主题色徽章「巴士线路 / 轻轨线路」+ 副标题 | 视觉断言 |
| AC-60 | 全站无「已带入收藏」横幅；无任何入口指向已下线四页 | grep + 浏览器 |

## 10. 边界与约束

- 客户端**禁止** import 含 `pg` 的服务端模块（走 `*-shared.ts` 或 type-only import）。
- 单文件 ≤300 行；新增组件单一职责。
- 不新增依赖；图标只用已锁定的 `@tabler/icons-react`；**禁 emoji 作图标**。
- 禁硬编码颜色（除 `#fff` / `#000`）；禁紫→粉渐变。
- 所有新 API 需说明限流归属（门已拆，但限流保留）。
- **不 push / 不打 tag / 不部署**；交付物 = 本地 `dev` 可访问链接。
