## 1. 产品定义

- **一句话描述**：M Map（澳搭車）——澳门通勤 + 全澳导航 PWA；本批让轻轨「读得了秒、算得准点」，并让导航的地图/定位/提醒全面向谷歌高德手感对齐。
- **目标用户**：作者本人（澳门在地通勤者，Android 为主力机型）。
- **核心问题**：① 轻轨秒级读秒未落到氹仔线（偏差数据已实测却未入库）；② 导航定位更新迟滞（15/30s 节流）、蓝点无动画、起终点钉不显示、提醒横幅在弹窗上、右侧栏冗余；③ 线路标签形态两轮返工（正确版 = v0.19.1，且 v3.1.1 白字丢失）。

## 3. 明确不做（Out-of-Scope — 锁定）

## 10. 边界与约束

- 无障碍：左上双态按钮 aria-label 随 pane 切换（读屏必查项）；触摸目标 ≥44×44；`prefers-reduced-motion` 下停动效。
- 性能：新增数据读取**不得**增加串行 DB 往返（预载窗口内并行/内存派生）；蓝点动画走合成层。
- 兼容：Android WebView 为**第一验收环境**（SVG var() 教训）；PWA 无 SW（缓存面小）。
- 合规：偏差表 `source`/`measured_on` 可溯源；报时备注句与「推算」角标为合规要求（铁律 9）。
- 文案门禁：所有 UI 文案改动过 `.verify/check-ui-copy.mjs`。
