2 · 层叠顺序（自下而上）

层z-index本页示意遮挡关系
.nav-map-wrap（含全部 marker）0（层叠上下文）底图 + 站点(90/95) + 红钉(110) + 绿钉(120) + 蓝点(128) + 车辆(130)内部 z 只在单元内比较；整体在浮层之下
.nav-brandbar20底部（导航态仅剩中列）与顶部横幅物理不冲突
.nav-locate-fab24右侧浮动定位图标（帧 A–D 均在上沿上方 12px）< 面板(70) 但**位置在面板之上方** ⇒ 不遮挡
.route-sheet（面板 + 头部按钮）70底部面板（左上双态 + 右上刷新）覆盖 FAB 的**下方**区域；与横幅不越界
.nav-card-overlay（车卡/站卡）90帧 C 底部信息卡底部锚定；与顶部横幅无交叠
.nav-alarm--top（下车横幅）94帧 A–D 顶部横幅最上层：永不被面板/车卡遮（AC-81）
为什么地图 marker「z110~130」不会压住浮层？ —— .nav-shell--full .nav-map-wrap{ position:fixed; z-index:0 } 使其成为**层叠上下文**， 内部所有 AMap marker 只彼此比较，**整体以 z0** 参与根层叠 ⇒ 不压 24/70/90/94（AC-13 层叠上下文教训的又一体现）。
