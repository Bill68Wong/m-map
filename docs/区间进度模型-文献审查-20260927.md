# 区间进度模型 · 文献审查报告（问题 → 分析 → 解决）

> 审查对象：站间时长模型（量化方案）+ 区间进度模型（今日调研）
> 方法：以外部研究文献为镜，按六个维度逐一「提出问题 → 分析问题 → 解决问题」
> 文献范围：公交 ETA 预测综述（Reich et al. 2019）· AVL/GPS 机器学习方法（TCD 2020）· 混合交通大数据建模（Springer 2025）· 地图匹配（Newson & Krumm 2009 及开源实现）· 不确定性量化（Dresden ICRAT 2024 / diva-portal）· 中文公交工业实践（公共交通资讯 2026）· 域偏移与校准（MDPI 2026）

---

## 0. 审查结论（先给结论）

**三个「与文献一致」**（我们的选择被文献支持）：
1. **特征体系一致**：文献常用「出发时刻 / 星期 / 日型」——我们的「时段五桶 + 工作日/周末」与文献特征范式吻合；
2. **归一化思路一致**：文献指出「两对象间行程时间**归一化后**更有意义」——我们的 h(p) 曲线本质就是「按路程比例归一化的剩余时间」；
3. **轻量路线成立**：文献明确指出「统计类方法在**数据有限、运营模式稳定**时很有吸引力」，且工业界成熟系统多采用「轻量主模型 + 修正层」混合架构——与我们「经验曲线 + 融合 + 质量门」的定位直接对应。

**三个「我们做得比文献批评的更好」**（Reich 2019 对领域的三大批评）：
- 批评①「评估指标五花八门、无法比较」→ 我们：A/B/D/E2 四模型同基准、按场次切分、MADE/P90 双指标、脚本可复跑；
- 批评②「经常缺少基准算法」→ 我们：每个结论都有「无信息基线」对照（如跨海段 2.11 vs 0.28）；
- 批评③「代码不公开、无法复现」→ 我们：全部实验脚本 `.verify/_track-progress-*.mjs` 可复跑。

**四个「明确短板」**（下文各维度展开，均有低成本解法）：
1. 螺旋坡类**拓扑难点**（几何投影的圈层混淆）——已实测（T355/T560），有解（连续性约束 + 段级信任度 + 融合兜底）；
2. **异常事件无修正**（事故/施工/台风）——文献共性问题，解法：轻量「事件系数」+ 定期重训；
3. **不确定性沟通不足**——我们已有 P90/覆盖率评估能力，但显示层未用；
4. **缺少跨环境复评机制**——域偏移文献警告「换环境后模型失效」，我们需固化「重训+复评」流程。

**一个定位声明**：我们做的是「**线路约束下的 1D 沿线定位**」（已知车辆在哪条线上，只求沿线里程），比通用路网 2D map-matching 简单一个量级——几何投影 + 轻量连续性约束即可，**不需要完整 HMM**；但螺旋坡这类「2D 空间折叠」场景需要从 HMM 家族借「过渡概率」思想补强（见维度一）。

## 维度一：定位与匹配——几何投影 vs HMM

**【问题】**（文献）地图匹配的 SOTA 是 **HMM + Viterbi**（Newson & Krumm 2009）：把每个 GPS 点作为观测、「真实道路位置」作为隐状态，用「发射概率（点到路的距离）+ 过渡概率（相邻候选点的路由可达性）」联合求解最可能序列。文献明确批评**纯几何最近投影**：「对离群与噪声不鲁棒，除非轨迹本身与路网高度贴合，否则匹配大多不准」（Willey 2024 benchmark 论文）。我们的模型正是几何最近投影——**在样本上它很准（2-3m），但 T355/T560 螺旋坡已实测失败模式**：p 卡住 75 秒后突跳、从 1.0 回退到 0.3（圈层混淆——螺旋不同圈层在 2D 平面上高度重叠）。

**【分析】**（我们）与通用 map-matching 不同：我们已有「车辆线路约束」（DSAT 报站给出路线 + 方向），未知的只是「沿线里程」——1D 定位问题。失败模式分析：
- 平行/重叠路段（往返合一线、螺旋匝道）：2D 最近点可能落在**另一圈/另一方向**；
- 数据密度：15s 采样 + 车辆 40-60km/h → 每帧间距 150-250m——螺旋坡（直径 ~100m、多圈）上**连续帧可能落在相邻圈层**；
- 但实测：受影响的是**局部子集**（T355/T560 全段 601 个测试段中，p 回退点占 1.5%，其余段 0.6%）——且**融合模型自动吸收**（该子集 E2=0.38 分 vs 位置模型单独 0.63）。

**【解决】**
1. **连续性约束（轻量 HMM 思想的 1D 化）**：投影候选限制在「上一帧里程 ± 合理位移窗」内，且**强制里程单调不减**（车辆中段不掉头）——直接消灭「回退/跳圈」类错误；
2. **段级信任度**：离线统计每「线路×区间」的投影质量（中位距离、回退率），作为运行时白名单——低信任段**自动降权位置项**（融合公式里把 D 的权重从 0.5 降到 0.2 或 0，即退化为时间减法）；
3. **疑难区标注**：T355/T560 等已识别区域进入「观察名单」，随采集持续复核；
4. **长期**（如需）：对 3D 结构（螺旋/立交）引入「时序拓扑约束」（候选点按到达顺序成链）——即 HMM 的过渡概率思想，但限定在我们的线路图上，计算量极小。

## 维度二：模型架构——历史曲线 vs 机器学习

**【问题】**（文献）主流综述把方法分为：历史统计 / 参数模型（回归、Kalman）/ 非参数（k-NN、SVM、ANN）/ 深度学习（LSTM 等）/ 混合。多数研究结论「ML/DL 精度更优」；我们也**没有使用任何机器学习**——是否落后？

**【分析】**（我们 + 文献交叉）
- 文献的重要限定（TCD 2020）：**「历史类方法在交通条件稳定时表现良好，但对意外延误误差大」**——我们的场景：澳门巴士站间时长**模式高度稳定**（长段单次波动仅 ±3%），且我们对「意外延误」已有部分对冲（护栏 + 稳健统计 + 融合）；
- Fan et al.（2015, Macaecity）：**仅用「到站/离站时间信息」（无交通流数据）即可有效预测**——证明我们的数据底座（报站事件 + 位置）足够支撑轻量模型；
- **我们的模型本质是「非参数条件分位数曲线」**（h 曲线 = 按路程比例分桶的经验分位数），与 ML 的「随机森林分位回归 / 分位神经网络」同属分位数预测家族——只是我们用手工分桶代替了学习；
- **代价权衡**：ML/DL 需要训练管线、超参调优、可解释性差、部署重（文献本身也承认「ANN 精度依赖训练过程」）；个人项目的维护约束下，**「可复跑、可解释、零训练」是真实优势**。

**【解决】**
1. **保持轻量主线**——已被实测验证（融合 0.45 分 / 跨海 0.32 分），且文献支持「运营稳定时统计方法有吸引力」；
2. **预留「残差学习」升级路径**（如果日后要上 ML）：不替换主模型，只学「现行模型预测 vs 实际」的残差修正项——数据需求小、增量交付、可随时回退；
3. **定期重训 h 曲线**（版本化）+ **异常事件轻量修正**（见维度三）——先把「非 ML 手段能拿的收益」拿完，再评估 ML 的边际价值。

## 维度三：特征与信息源——我们缺什么

**【问题】**（文献）常用特征：时段/星期/日型（已有 ✓）· **天气**（降水对延误影响显著——Chen et al.）· **信号灯配时**（国内工业实践与交警平台对接）· **客流/停站时间**（APC 数据）· 交通流（线圈/蓝牙）。我们只有时间 + 位置——差距有多大？

**【分析】**（逐项）
| 信息源 | 文献价值 | 我们的可获取性 | 结论 |
|---|---|---|---|
| 天气 | 降水显著影响 | **澳门气象局开放数据**（可免费接入）| ✅ 值得做（低成本高价值，尤其台风季）|
| 信号灯配时 | 提升显著（国内实践）| 无公开数据（DSAT 不开放）| ⚠️ 用 h 曲线的静止分量近似（已做）|
| 客流/停站 | 影响停站时长 | 无 APC 数据（DSAT 无乘客数）| ❌ 放弃（不可得）|
| 交通流 | 显著 | 无（无路侧设备）| ⚠️ 已用「实测运行时长」间接蕴含 |

**【解决】**
1. **天气接入（推荐）**：获取澳门气象局预警数据（暴雨/台风信号）→ 定义「全局时段系数」（如暴雨 ×1.15）或「当天事件标记」——文献支持、成本低、台风季价值明确；
2. 信号灯/客流维持「隐含吸收」策略（h 曲线已包含其统计效应）——不追求显式建模；
3. **建立「事件修正」操作**：大型活动/道路施工时，人工标记当天系数（一次按钮，全局生效）——对应文献的「small-large model 协作」中「大模型语义修正」的极简版。

## 维度四：不确定性量化——文献的普遍短板与我们

**【问题】**（文献）不确定性研究「相对较少」；航空领域研究（Dresden ICRAT 2024）发现：模型在样本外情形下**大幅低估不确定性**（PICP 指标暴露），「对安全关键系统不可接受」。我们如何？

**【分析】**（我们已有的事实）
- 我们在**量化方案阶段就已经发现过同类问题**：现有「约 X~Y 分」区间实测覆盖率仅 24%（名义区间严重低估不确定性）——**正是文献警告的现象，并且我们已经用数据暴露了它**；
- 今日进度模型进一步提供了「条件不确定性」结构：误差随进度收窄（0.58→0.30 分）——**这是一个天然的、可沟通的不确定性曲线**。

**【解决】**
1. **显示层策略**：单值 + 「约」字（移动场景窄区间意义弱）——已在方案中定；
2. **区间透明化（如未来需要）**：用「实测覆盖率」而非「名义分位」标定区间宽度（我们已具备复跑评估的能力）；
3. **建立 PICP 式验收**：将「覆盖率」纳入模型迭代的验收指标（与 MADE/P90 并列）。

## 维度五：评估严谨性——对照领域批评自查

**【问题】**（文献）Reich 2019 综述的核心批评：领域内**评估标准混乱、缺基准、难复现**——我们的评估经得起检验吗？

**【分析】**（自查）
| 文献批评 | 我们的做法 | 判定 |
|---|---|---|
| 指标不可比 | MADE + P90 双指标，且可换算 MAPE 对标文献 | ✅（可补 MAPE 报告）|
| 缺基准算法 | 每个实验都有 A（无信息）基线 + 多方案对照 | ✅ |
| 数据泄漏/切分随意 | **按场次时间切分**（28 场训练→13 场测试），并处理了「同场泄漏」 | ✅ |
| 不可复现 | 全部脚本可复跑（`.verify/`，输入=采集数据，输出=报告）| ✅ |
| 样本外情形 | **已专门检查**（中途打开场景、噪声鲁棒性）| ✅ |

**【解决】**
1. 补一份「MAPE 对标说明」（我们的 MADE 0.45 分在典型 8 分钟行程上 ≈ MAPE ~5-6%，与文献报告的「MAPE <10%」区间可对标）；
2. 固化「重训即复评」流程：h 曲线每次重训自动生成对比报告（新旧模型 + 基线的三方对照）；
3. （可选）公开实验档案（个人非商业项目，注意合规红线不变）。

## 维度六：部署与运维——重资产 vs 轻资产

**【问题】**（文献）国内工业实践采用重资产方案：扩展卡尔曼 + XGBoost 混合、**信号灯平台对接**、隧道段**基站+惯性导航**、**数字孪生**异常根因分析。我们只有 DSAT 公开接口 + 自建模型——如何定位？

**【分析】**
- 重资产方案的每项能力都对应**数据源投资**（信号灯数据、惯导设备、视频客流）——个人项目不可及，且文献也承认工业系统「数据设施成熟、分析能力有限」的普遍现状（马来西亚综述）；
- 但有个可借鉴的架构思想：**small–large model collaboration**——轻量高频主预测 + 低频语义修正（外部事件解释）——**我们的「融合模型 + 事件系数 + 人工标记」恰好是这个思想的最简版**；
- 我们的独有优势：**已验证的全链路 + 10 万段级实测数据 + 可复跑实验体系**——对个人项目而言是「研究级严谨 + 生产级轻量」的组合。

**【解决】**
1. 维持轻量架构（服务端纯函数 + 常量曲线表）；
2. **监控闭环**：把「预测误差在线统计」接入观测（导航观测钩子 → 定期出误差报告）——文献强调「持续性评估」；
3. **退化策略**：位置不可用 → 时间减法；时间不可用 → 区间中位；全不可用 → 不显示具体分钟（宁缺勿错）——已在模型设计覆盖。
