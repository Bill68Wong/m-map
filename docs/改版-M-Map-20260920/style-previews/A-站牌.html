Direction A · M Map Redesign

「站牌」SIGNBOARD

像澳门街头的巴士站牌：白底黑字、粗描边、线路色是唯一的花。冷雾白底图上只留墨黑与澳门绿；卡片用 1.5px 实描边 + 3px 硬投影代替模糊阴影——把界面做成"实体",而不是"一层浮灰"。

注：本页展示方向 A 的形态与排版（结构基准）。最终配色以 V2「蓝主」为准 —— accent = 青花蓝 #1B4D8F、边框亦为青花蓝，见 variants/V2-蓝主.html 与 04-design-tokens.md。本页出现的澳门绿已成为最终方案的「辅主题色」（非主色）。

两类收藏用不同形态表达：地点对 = 发丝线行（左贴纸式汉字标记），路线方案 = 带纵向色轨的卡。数据结构不同，就不该塞进同一种盒子。
线路标签（用户定义）：单码 = 主题色圆角矩形标签；多码并列 = 同一墨色组胶囊内、以白色斜杠分隔（「25 / MT4」＝这一段有两条线可选）；换乘仍用箭头「→」（行程推进，与「/」语义不同）。
