「自动 vs 手改」的表达规则

  • 灰度 = 系统给的：自动值用 --muted 灰字 + 「自动」标记
  • 实色 = 你定的：手改值用 --fg 加粗 + 「手改」青花蓝标记 + 「还原为自动」
  • 虚线框 = 未编排；实线蓝框 = 已手改
  • 与全站既有口径一致（.rc-est「估算」也是灰）

控件选型

  • 速度 / 用时 = 五档分段选择，不用滑杆：① 手机上滑杆拖不准；② 滑杆暗示"连续可调"（不存在）；③ 五档与 步行速度五档-文献依据 一一对应
  • 步行路程不做自由输入：距离由端点决定，改端点即改距离
  • 换乘用空间化的「＋ 插入换乘」，而不是下拉列表

方案卡列表

  • 100% 复用 .card.rc，零新样式
  • 只见 一组「当下最快」，只高亮第一张（青花蓝 2px 框 + 硬投影）
  • 排序：用时 / 换乘少 / 步行少
  • 来源徽章用 §A 的「本地补充」（青花蓝 chip，替代旧 .rc-badge-local 的灰 pill）

需新增的图标（Icon.tsx）

  • add 新建/插入 · edit 编辑/重命名 · more ⋯ 菜单
  • dragHandle 排序把手 · pinTop 置顶 · undo 还原为自动
