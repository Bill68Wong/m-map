关键尺寸

  • 顶部锚点 top: 14vh（默认）· 展开 6vh · 收起 62vh
  • 水平 left/right: 12px → 内容宽 = 视口 − 24px
  • 圆角 --radius-sheet 14px（四角）
  • grip 命中区 44×24，视觉条 36×4
  • 结果行高 ≥52px（≥44 命中）

手势与滚动隔离

  • 只在 grip + 头部区（y<56px） 起拖；|Δx|>|Δy| 则放弃接管
  • 上界橡皮筋 ×0.35；下拖 >100px 或速度 >0.5px/ms → 关闭
  • 弹层 touch-action: none；内容区 pan-y
  • 列表 overscroll-behavior: contain（滚到底不传给地图）
  • 软键盘：监听 visualViewport 抬升，列表自动滚到可见行
  • prefers-reduced-motion → 去掉橡皮筋与吸附动画

每步高度不同

  • ① 选目的地 14vh
  • ② 确认位置 62vh（收小 · 主角是地图）
  • ③ 选出发地 14vh
  • ④ 出发 46vh（只留 OD + 按钮）
