## 1. 产品定义

- **一句话描述**：将首页「出发 → 推荐 → 详情」升级为**谷歌地图式三档可拖拽面板**——推荐为近全屏，点卡片后详情降到下半屏、上半屏地图浮出「路线总览」（乘车区间彩色线、区间外灰色线、起终点标记、全线实时巴士）；详情可上拖回近全屏、可关闭回推荐；全程地图不被盖死、无遮罩、跟手丝滑。
- **目标用户**：唯一用户（作者本人，澳科大通勤）。
- **核心问题**：① 整页跳转/加载延迟；② 详情与地图割裂；③ 车辆图标拖动时飘移（React 覆盖层方案）；④ `/nav`、`/nav/detail` 两个多余页面。

## 10. 边界与约束

- 主视口 390×844；iOS/Android 安全区（`--safe-top` / `--safe-bottom`）。
- 地图失败不阻塞（面板/列表/详情照常）；面板挂 `.nav-map-wrap` 之外（AC-13 教训）。
- 取景**全部自算**（`fit-box` 模式扩展 `view` prop）；**禁用** `setBounds` / `setFitView`（会撑到珠海）。
- 坐标：切割用「最近顶点 + 容差 80m」；超差降级（整线着色不画灰 + `console.warn`）。
- 车辆：每簇一个 React root（`Map<key, {marker, root}>` 严格配对）；合并仅在数据刷新 + `moveend/zoomend`（节流 120ms）重算；`anchor:'center'`；`.vbus-wrap` 移除 position/left/top/transform 四行。
- 观测钩子（**契约锁定 2026-09-24（含改名裁决）**，QA 断言以此为准，不再改名）：`data-sheet-state=recommend|detail`（当前 pane；⚠️ 用 `data-sheet-state` 而非 `data-state`——后者被车辆图标占用（moving|stopping|terminal|lost|unknown），避免断言选择器歧义）/ `data-detent=peek|half|full`（当前档位）/ `data-phase=loading|ready|empty|failed`（面板内容阶段）/ `data-live=on|none|ended`（实时车辆态）/ `data-map=ok|failed`（地图态）/ `data-overview-legs=<number>`（详情已绘制乘车彩段数，0=不可绘/未就绪）；关闭复位 `--sheet-y-anim:100dvh`；保持既有 `data-nav-zoom` / `data-station-count` 等不变。

## 11. 内嵌已知坑（从项目记忆拉取——开发时必须避开）

| 坑 | 根因 | 修法 |
|----|------|------|
| 层叠上下文 | `.nav-map-wrap` 是 `position:fixed; z-index:0` 上下文 | 面板/卡片一律挂 wrap 之外（Spec AC-13 历史） |
| `setBounds`/`setFitView` 撑到珠海 | `setLimitBounds(澳门)` 场景视野失控 | 取景全自算（`NavMap.tsx` 三处踩坑注释） |
| effect 依赖 + 提前 return | `if (phase!=="ready") return` + 依赖缺 `phase` = 永不启动 | 新增 effect 依赖与守卫一起核（v2.11.0 血的教训） |
| fail-closed 白名单 | middleware 默认拒绝 | `/api/nav` 前缀**保留**（详情弹窗依赖）；删页重定向必须放 middleware 鉴权之前 |
| 坐标不同源 | `route_shapes`（高德）vs `stations`（DSAT→GCJ） | 最近顶点 + 容差 80m；环线用闭合检测 + 环绕切分 |
| `createRoot` 泄漏 | 多 root 与高德容器生命周期 | `Map` 严格配对，卸载遍历清理 |
| 改 `.json` 写 BOM | PowerShell `Set-Content` | 用编辑器工具（`package.json` 加 script 也适用） |
| `npx` 静默失效 | 本机沙箱 | node 直调 CLI 实体（构建：`node node_modules/next/dist/bin/next`） |
| 构建批量删除守卫 | safe-delete 阈值 | 前缀 `CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD=999999` |
| 反引号走 `node -e` | 宿主拦截 | 一律落 `.verify/*.mjs` 脚本执行 |
| 高德自定义样式幻觉接口 | 常见于 AI 编造 | `setMapStyle({styleJson})` / `setFeatures(['point:none'])` / `AMap.createStyleEditor()` **均不存在**；接线只用初始化参数 `mapStyle: 'amap://styles/<id>'` |

**真机流程（390×844，`next start` + Playwright/真机）**：
1. 首页 → 选点 → 「出发」→ 面板 full（顶边 96–128）→ 顶部地图带可拖。
