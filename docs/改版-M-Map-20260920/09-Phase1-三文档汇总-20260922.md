## 一、专家调研结论摘要

### 1.1 产品（PM · 许清楚）

**竞品调研（9 个：5 直接 + 4 替代）**

| 竞品 | 怎么做实时车辆 | 对本项目的启示 |
|---|---|---|
| **DSAT 官方「巴士報站」** | 地图绿图标=车位置；**蓝=新福利 / 橙=澳巴**（本地人已认得的约定） | **运营商标色直接用蓝/橙，零学习成本** |
| Citymapper | 点图标只给「最后更新时间」一句话（极克制） | **点车不必弹大窗** |
| Google Maps | 站点=圆/方内嵌载具符号；车辆=带方向箭头 | 形状+颜色双通道 |
| 香港城巴 | 信息卡给「车辆与所选站的**实际距离**」 | **卡里放可行动数字** |
| KMB 1933 | 运营方用**图形标识**而非仅颜色 | 澳巴/新福利加车头徽记 |
| myTrip (UK) | 行驶=带方向巴士图标、静止=圆圈 | 状态用形状区分 |
| CityBus.in.ua | 外圈弧=方向、弧宽=速度；卡内显示数据时间 | **超时变色**值得借鉴 |
| MTA Bus Time | 车辆沿路线以箭头显示 | — |
| Transit App | 众包 GO 数据 1-2s 延迟 | — |

**差评与市场空白（5 条，全部有出处）**

1. **「消失的巴士」**（UDN 报道）—— 官方规则「两站间行驶超 10 分钟即判异常并剔除」，导致 App 里车会**突然消失**，用户以为车没了 ⇒ **我们必须显式标示「信号丢失」，绝不静默移除**
2. **更新滞后 / 跳站**（澳门报站 App Store 评论；武汉 572 路 GPS 跳站致错过换乘）⇒ **必须显示「最后更新时间」**
3. **拥挤度缺失**（澳门报站评论；官方载客估算仅覆盖 34.5% 车辆）⇒ 本项目已有 `passengerFlow` 字段，可作差异点
4. 稳定性差（澳门报站频繁闪退）
5. 广告与耗电（Moovit 约 70% 用户抱怨广告）⇒ **本项目无广告、轻量是差异点**

**用户最在意的 3 件事（优先级）**
1. **数据新鲜度与可信**（决定「跑不跑得及」）⇒ 显式「最后更新时间」+ 刷新倒计时
2. **车辆状态一眼可辨**（行驶/停靠/方向/是否末班，决定行动）
3. **换向不串车**（换向即刷新，避免看到反方向的车）

**借鉴做法**：图标参考 myTrip（状态用形状）+ Citybus.in.ua（数据超时变色）；信息卡字段直接采用其范式（运营商+车牌+方向+状态+车速+区间+数据时间），**与本轮需求字段完全吻合**；重叠用数字角标（业界通用）；**信号丢失必须显式标示**。

### 1.2 架构（架构师 · 高见远）

**技术方案（7 问逐条已答，此处只列结论）**

| 项 | 结论 |
|---|---|
| **新端点** | `GET /api/route-vehicles?code=<线>&dir=<0\|1>&kind=bus`（只读） |
| **DSAT 封装** | `client.ts` 新增 `getBusLocations(routeName, dir)`；**`DsatPurpose` 扩展 `"live_pos"`** |
| **`routeCode`** | **本地推导，不入库**：线路号**右对齐补零到 5 位**（`26→00026`、`51A→0051A`、`MT1→00MT1`、`N6→000N6`）。依据 `scripts/track-collect.mjs:146-153`（10/10 实测） |
| **缓存** | 动态数据**不跨用户缓存**；可加 10s 内存缓存（键 `code\|dir`）对齐冷却 |
| **10 秒冷却** | **前端 disabled 为主**（UI + 自动/手动共用）+ 服务端限流兜底。原因：Vercel 多实例内存不共享，纯服务端冷却会失效 |
| **坐标转换** | `wgs84ToGcj02`（`coord.ts:66`）**已与高德官方逐点比对，最大差 0.32m**；**服务端转**（同 `/api/stations` 口径） |
| **行驶区间** | 位置接口**无挂载站**、报站接口**无坐标** —— 两者互为补集。**推荐：坐标用位置接口；区间/状态用报站接口**（复用 `dsat/eta.ts` 口径）。若只用位置接口：用其 `stationInfoList[]` 做**最近站匹配**（haversine，阈值 120m） |
| **偏差值存储** | **推荐常量配置 `src/config/lrt.ts`**（`-5s/+40s`、`1'40"/2'15"` 是固定实测值，仅服务 2 条一站线）。**否决**「加到 `lrt_timetables`」（该表是 站×线×方向×班别 粒度，偏差是线路级，**粒度错配**） |
| **换乘站切色** | **可行**，`linear-gradient` 硬停止即可，无需 `conic-gradient`；白描边用「外层白底 wrapper + 内层渐变」 |
| **换向根因** | `NavMap.tsx:819-837` 的 `for(shapes)` **全画** ⇒ 改：`pickedLine` 增 `dir`，只画 `filter(dir)`；**单向线判据 = `shapes.length > 1`**（76 条单向线自然无按钮）；切换**要重算 `setBounds`** |

**风险清单（6 条）**
1. **配额/熔断**：`live_pos` 必须像 `recommend` 一样**记账但不参与熔断判定**（`risk.ts:28-30` 需扩）——否则刷新会撞开 30 分钟静默，**连累计时器的自动车距快照一起哑掉**
2. **多实例冷却失效**（见上）
3. **车辆 GPS 漂移** ⇒ 最近站匹配须设阈值
4. **换向/刷新须先 remove 旧 marker 防泄漏**
5. **`routeCode` 传错会静默返回空**（不报错）⇒ 须断言
6. **新 API 必须加 `PUBLIC_PREFIXES`**（`middleware.ts:39-59`）—— 已踩两次

**⚠️ 三项不可行/纠正**
1. **轻轨线路无实时车辆**（DSAT 是巴士系统）⇒ 轻轨路线查看模式**只能画线、无车点**
2. **`routeCode` 实为 5 位**（需求文档写 6 位，有误）
3. **「一次调用同得精确坐标 + 挂载站」不可行**（两接口互为补集）

### 1.3 设计（设计师 · 颜好看）

**对标品牌**：沿用 M Map 已锁定的**「澳门街牌」设计语言**（青花蓝 `#1B4D8F` + 硬投影 + 发丝线 + 2px butt-miter + 图标三档 16/20/24），对标 **Apple Maps**（浮层落拇指区）+ **Citymapper**（车辆/合并/信息卡范式）+ **官方巴士报站**（蓝=新福利·橙=澳巴）。**不换语言**——本次是加功能。

**6 个设计问题的规格**

| # | 项 | 规格摘要 |
|---|---|---|
| 1 | **车辆图标** | 画布 32×32、命中区 44×44；**自绘扁平插画 SVG**（属插画非功能图标，不占 Tabler 名额）；车头**恒朝上**、正交俯视；圆角矩形车身 r4 + 挡风带 + 后视镜 + 车顶线；**2px 硬描边 + 3px 硬投影 + 1.5px 白描边**（贴纸双描边，从灰底图上拎出）。**双通道**：车身色=运营商，轮廓/角标/透明度=状态 |

| 2 | **合并角标** | ≤28px 屏距合并为**一枚**图标（不叠车）+ 右上角标：16px Ø / `--fg` 底 / 白 11px·700 / 1.5px 白描边，锚 `top:-4px;right:-4px`；**≤9 显数字，>9 显 `9+`**；点合并图标→车辆列表 |
| 3 | **信息弹窗** | 底部卡（复用 `.nav-station-card` 位/z-30，落拇指区）：头部[插画 32]+运营商·车牌（mono）+✕ → 状态行[●状态词 + 右大号 tabular 车速] → **「行驶区间」横向微时间轴 rail**（线路主题色为轴，起点实心点/终点空心点，中段按"已行进"填一小段）→ 页脚 `--meta` 更新时间。进站态退化为单节点 `──▶ 进站 · T373 偉龍／科技大學` |
| 4 | **刷新冷却** | 竖排第三键 44×44 圆 + 1.5px 青花蓝 + 3px 硬投影。冷却中：图标淡出 0.25、**中心改显纯数字秒数**（mono 13/700 tabular，不带单位），外圈 **`conic-gradient` 进度环** 100%→0，整键降 `--muted` + 撤投影。`aria-label="刷新，7 秒后可再次刷新"`，冷却开始**播报一次不逐秒** |
| 5 | **站点图标** | 巴士站=**实心青花蓝圆点 Ø10**+1.5px 白描边+1px 深色外圈；轻轨站=**线路色方点 13×13 r3**+同款描边。「一眼分辨」靠**形状为主**（圆/方），尺寸（10 vs 13）为辅，颜色第三。路线模式下 on-route ×1.4、dim ×0.7+opacity .45 |
| | **换乘切色** | 纯 CSS `linear-gradient` + 白拼缝，颜色由行内 `--c1/--c2` 从线路数据注入：<br>**協和醫院**（水平切）：`linear-gradient(180deg, var(--c1) 0 calc(50% - 1px), #fff calc(50% - 1px) calc(50% + 1px), var(--c2) calc(50% + 1px) 100%)`<br>**蓮花**（斜切）：`linear-gradient(to top right, var(--c1) 0 calc(50% - 1.4px), #fff calc(50% - 1.4px) calc(50% + 1.4px), var(--c2) calc(50% + 1.4px) 100%)`<br>斜切白缝取 1.4px（≈1÷cos45°）以与水平缝**同视觉宽度** |
