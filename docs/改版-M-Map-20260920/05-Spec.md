## 1. 产品定义（锁定）

- **一句话**：MUST登校 品牌升级为 **M Map** —— 澳门全澳巴士/轻轨导航 PWA 的界面改版：全屏地图首页 + 路线收藏 + 去 AI 化视觉体系。
- **目标用户**：澳门科技大学学生（住擎天汇）为主、少量同学；移动端为主，桌面端可用。
- **核心问题**：① 旧首页地图仅半屏、操作路径长 ② 无收藏能力 ③ 视觉"AI 模板感" ④ emoji 冒充图标。

## 3. 明确不做（锁定）

账号体系 / 收藏云同步 · **深色模式重排**（既有明暗双主题保持现状不动）· 收藏分组/导出/推送 · 方案冻结到班次 · **地图瓦片级裁剪** · **自绘边界**（合规红线）· 新后端接口 · i18n · 桌面端专用布局（仅"可用+地图铺满"）。

增补锁定：`STATION_MIN_ZOOM=16` 不变 · `/api/nav` 契约不动 · 坐标口径（GCJ-02）不动 · 收藏上限 200 条/类混合 LRU。

## 5. API 与数据（锁定）

- **本期无新增接口**；沿用：`/api/poi/suggest` · `/api/nav` · `/api/stations` · `/api/station/eta` 等。
- **无数据库变更**。
- 收藏数据结构（权威定义 = 02 §2.3，含 fingerprint 修订）：
  - `FavoritesFile{schemaVersion, updatedAt, items[]}`；
  - `PlaceFavorite`：`query`（= `parseNavParams().query`，回放唯一依据）；
  - `PlanFavorite`：`query` + **`fingerprint`**（= `rides.map(r=>\`${r.route}@${r.board}->${r.alight}\`).join("|")`，**不落 planId**）+ `snapshot`（仅展示，"保存于 MM-DD"）；
  - 回放：重算 → 按指纹比对 → 命中用**当前卡的 planId** 跳详情 / 未命中落 `/nav` + 「已重新规划」。
- `/favorites` 必须加入 `src/middleware.ts` 公开白名单（fail-closed）。

## 7. 设计（锁定 —— 全量以 `04-design-tokens.md` + `design-tokens.json` 为准）

- 方向 **A「站牌」**；主强调色 **青花蓝** `--sign-blue #1B4D8F`（deep `#16406F` / soft `#E6ECF6` / on `#FFFFFF`；hover `#17447D` / active `#123A66`）；**蓝的岗位**：CTA 底 / 选中态 / 主描边（蓝框）/ 地图边界线 / 焦点环。
- **辅主题色 澳门绿** `--brand-green #0B6E4F`（deep `#08543C` / soft `#DCEBE2`）：**仅**①正向状态语义（success 与它同源）②品牌点缀；**硬规则：同屏同焦点只出现一个品牌色；面积(蓝)≥面积(绿)**。官方绿 `#00795E` 仅作 `$alternateOfficial` 备用。
- **线路标签色 = 线路数据色**（`routes.color`，巴士按公司/轻轨按线），**不纳入 token、不随主题变化、禁止硬编码**；形态：单码=圆角矩形（r5–6）；多码=**墨色组胶囊承底 + 白斜杠**（已裁定默认形态）；换乘=箭头 `→`。
- 字体 Barlow / Noto Sans SC / JetBrains Mono；8 级字号（11~32）；字距阶梯（-0.02em/-0.01em/0/+0.09em）；数字一律 `tabular-nums`。
- 圆角 chip6/group7/btn8（**非 pill**）/card10/sheet14；**零模糊阴影**（硬投影 `3px 3px 0` + `--hairline`；唯一例外 `--shadow-sheet`）。
- 图标：**2px 描边、butt/miter**、16/20/24 三档、24 viewBox、`currentColor`，**★ 全站范围**；**工程方案（锁定）**：自研单一 `<Icon>` 包装组件（内部固定 `stroke=2` / `strokeLinecap="butt"` / `strokeLinejoin="miter"`，`size` 约束为 `16｜20｜24` 联合类型），**全站只从它出图标**——单一入口、单一风格真源，不依赖 CSS 继承的偶然性。

## 8. 验收（锁定）

- 功能验收：**以 `01-需求规格.md` §10（AC-1.1 ~ AC-6.4）+ §7 收藏规格**为准。
- 技术验收：**以 `02-技术方案.md` §3.5 端到端**为准（含：范围限制回弹、遮罩、版权可见、4 入口收藏、失效重算、空态、隐私模式、白名单）。
- **P0 扫描（QA 执行）**：全站 `src/**` 正则扫描——emoji/Unicode 图标 **零命中**；紫→粉渐变色值 **零命中**；模板文案 **零命中**。
- 双视口：移动 430×932 + 桌面 1440（地图铺满、底导、弹层、收藏页）。

## 9. 边界与约束（锁定）

- **合规**：地图源=高德白名单；边界=高德官方数据；不遮挡 Logo/审图号；不缓存瓦片；边界坐标**仅内存/sessionStorage**；收藏数据不出设备；不采集上报。
- 移动优先（<640 第一现场）；iOS 安全区（`env(safe-area-inset-bottom)`）；触达目标 ≥44；对比度 ≥4.5:1。
- 性能：首屏可交互 <3s；地图懒加载不阻塞搜索/出发；收藏页**不批量重算**。
- P0 团队红线：无 emoji 图标 / 无紫粉渐变 / 无模板文案。

## 10. 内嵌已知坑（开发必读）

**收藏侧**：F1 SSR 水合（`"use client"`+mounted 守卫）· F2 Safari ITP 清 storage（容错+文案）· F3 脏数据逐条校验剔除 · F4 schema 演进未知版只读不写 · F5 `gps` 端点回放时重新定位 · F6 写放大可接受（防抖可选）。
**地图/布局侧**：① 全屏地图吞滚动手势（抽屉 `overflow-y:auto`+`touchAction:pan-y`；展开时 `map.setStatus({dragEnable:false})`）② 容器全屏化后 `map.resize()`/orientationchange ③ iOS 安全区 ④ **不遮挡高德 Logo/审图号** ⑤ `setLimitBounds` 与初始视野配套 ⑥ **遮罩绕向（开发首日探针 V3 门禁；不过→降级仅范围限制交付）** ⑦ 边界缓存合规 ⑧ `middleware` 白名单 ⑨ 共享 CSS 类回归（`.nav-map` 影响 `/nav`）。
**开工门禁**：S1 前先跑 **V3 探针**（带洞多边形"多洞+绕向"最小 demo）；V1/V2/V6 紧随。
