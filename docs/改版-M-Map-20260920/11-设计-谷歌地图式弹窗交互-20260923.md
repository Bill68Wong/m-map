# M Map 设计规范 · 「出发 → 推荐 → 详情」谷歌地图式弹窗

> 生成日期：2026-09-23 | 设计师：颜好看 | 参考：`03-设计方向.md` / `05-Spec.md` / `10-Spec-实时巴士位置-20260923.md`
> 三轴刻度：**Variance 5 / Motion 6 / Density 4**（移动优先 390×844，地图为主舞台）
> 适用：首页地图上的**推荐弹窗**（`.result-sheet` 新版）与**详情弹窗**（`.detail-sheet` 新版）的手感、停靠、路线总览视觉。
> 注意：本轮**只升级体验层**：不新增视觉体系、不改巴士车辆图标（保持运营商涂装 + 5 状态）、不改深色模式。

## 0. 一句话结论（给架构师/前端）

把现有两个「全屏铺满」弹窗，改为**同一套可变高度底部 sheet（三档 peek/half/full）**：
- **推荐弹窗** = 默认**近全屏**，顶部恒定留一条**可交互地图带**（`--sheet-top-full` ≈ 96–128px，面板打开期间隐藏搜索框）；
- **详情弹窗** = 默认**下半屏 50vh**，开卡时上半屏是**路线总览**；
- **两态共用三档**：full（近全屏）/ half（下半屏 50vh）/ **peek（20% 收起档，R3 新增）**；peek 显示一行 OD + 一行指标摘要；
- **关闭链路**：推荐 peek 再下拉 = 关地图；详情 peek 再下拉 = 回推荐（非关地图）；
- 全程 **无 scrim**（地图始终可见可交互，与 Google Maps 一致）；
- 位移只用 `transform: translateY()`，拖动中 **0ms（跟手）**、释放后 **260ms 标准缓动**（开/关/换档统一，R4），**禁用任何弹跳/弹性曲线**。

## 1. Google Maps Bottom Sheet 调研结论

> 来源：Google Maps Android 25.16 的 sheet 改版（Yahoo Tech / GeekChamp / T3 报道）+ 复刻该模式的 FlexibleBottomSheet 实现（ProAndroidDev，对齐 Google Maps 参数）。网络公开的"像素级"数值有限，以下**比例值为行业最佳实践与本项目落地值**，标注了「Google 参考」与「M Map 落地」。

| 项目 | Google Maps 参考 | M Map 落地 | 说明 |
|---|---|---|---|
| 停靠点数量 | 3（peek / 中 / 全） | **3（peek / half / full）** | R3 起对齐：三档齐备 |
| 摘要小档 | `slightly ≈ 0.18–0.25` | **peek = 20vh（0.20）** | 与 Google `slightlyExpanded` 一致；见 §3.1 摘要设计 |
| 近全屏档高度 | `fullyExpanded ≈ 0.90`（顶部留约 10% 地图） | `100dvh − --sheet-top-full`（clamp 96–128px） | 390×844 实际 ≈ 89dvh，与 0.90 一致 |
| 中档高度 | `intermediately ≈ 0.50` | `50dvh`（详情「下半屏」） | 上半屏完整让给路线总览 |
| Scrim 压暗 | **无 scrim**，地图全交互 | **无 scrim**，地图全交互 | 与 Google Maps 一致，且保护现有地图手势 |
| 圆角 | 顶部大圆角 | `--radius-sheet` = **14px** | 复用现有 Token（卡片上限 12–16） |
| 把手 grabber | 顶部居中短横条 | **36×4px**，`--border-2`，命中 44×24 | 复用现有 `.step-sheet__grip` 规格 |
| 阴影 | 柔和抬升 | `--shadow-sheet`（唯一允许柔和抬升） | 复用现有 Token |
| 展开/收起动效 | 平滑收敛，无弹跳 | **260ms + `--sheet-ease (0.32,0.72,0,1)`** | 项目禁用弹跳曲线 |
| 内容随档位变化 | `targetValue` 触发即变 | 拖动一开始（target 变化）即切换内容 | 手感更跟手（不等内容归位） |
| 嵌套滚动 | 内容区滚到底再下拉才收起 | 内容区 `overscroll-behavior: contain`；顶部下拉才收起 | 复用现有 `.step-sheet__body` 策略 |

**一句话提炼**：Google Maps 的精髓 = **「地图永不被盖死 + 无 scrim + 跟手拖拽 + 平滑无弹跳」**，而不是某个固定高度。

## 2. 新增 Design Token（A2 / C-extension）

> 全部**引用现有 Token 派生**，零硬编码色值；写入 `src/app/globals.css` 的 `:root`（深色 `@media` 块同步补值，保证新组件不裸奔）。

```css
:root {
  /* ── 停靠点几何（推荐/详情共用） ──
     最终口径（架构师拍板，living-spec §2.2）：面板打开期间**隐藏顶部搜索框**，
       故顶边取「纯地图带」高度，无需为搜索框让位（露出的是完整可交互地图带，非 12px 缝）。 */
  --sheet-top-full: clamp(max(calc(var(--safe-top) + 44px), 12vh), 96px, 128px); /* 推荐默认 / 详情上拖档 */
  --sheet-top-half: 50vh;             /* 详情默认「下半屏」档 */
  --sheet-y: var(--sheet-top-full);   /* 运行时档位位移（JS 写入；见 §4.5 双变量建议） */
  --sheet-radius: var(--radius-sheet);        /* 顶部圆角 14px */
  --sheet-hairline: 1px solid var(--border);  /* 顶部发丝线（与全站卡片语言一致） */
  --sheet-shadow: var(--shadow-sheet);        /* 复用：唯一允许的柔和抬升 */

  /* ── 把手 grabber（与现有 .step-sheet__grip 完全一致） ── */
  --grab-w: 36px;      /* 视觉条 36×4 */
  --grab-h: 4px;
  --grab-hit-h: 24px;  /* 命中区 44×24（WCAG） */
  --grab-color: var(--border-2);        /* 静止 */
  --grab-color-active: var(--muted);    /* 拖动中（更强的反馈） */

  /* ── 拖拽判定（跟手核心参数） ── */
  --drag-switch-ratio: 0.28;   /* 位移 > 相邻档间距 28% ⇒ 换档 */
  --drag-flick-v: 0.5;         /* 释放速度 |v| > 0.5px/ms ⇒ 沿速度方向翻档 */
  --drag-close-dist: 96px;     /* 下拉超过此位移 ⇒ 关闭（回上一层） */
  --drag-close-v: 0.5;         /* 或速度 < -0.5px/ms 且位移 > 32px ⇒ 关闭 */

  /* ── 过渡时长（全部 ≤260ms；≤400ms 红线内）──
     R4：open / settle / close **统一 260ms**——实现用**单条** `transition: transform var(--sheet-dur-settle)`
     覆盖打开/换档/关闭；下三枚同值（语义别名）。原 300ms/240ms 作废。 */
  --sheet-dur-open: 260ms;             /* 打开 / 推荐↔详情切换（= settle） */
  --sheet-dur-settle: 260ms;           /* 释放归位到最近档（实现主用） */
  --sheet-dur-close: 260ms;            /* 关闭 / 下拉关闭（= settle） */
  --sheet-dur-scrim: var(--dur-base);  /* 200ms：彩色区间线显隐 / 搜索框淡出等 */
  --sheet-ease: cubic-bezier(0.32, 0.72, 0, 1); /* 标准减速曲线（控制点 y 均 ≥0、无 overshoot，禁用弹跳） */

  /* ── 地图专用·未乘车段灰线（C-extension，本项目地图专属）──
     由现有 --border-2 / --meta 同族派生 ⇒ 不写死灰值，深色自动跟随 */
  --map-line-dim: color-mix(in srgb, var(--border-2) 55%, var(--meta));
  /* 浅色实际 ≈ #9FA5AE（中灰，底图上清晰）；深色自动派生出 ~#7E8390 */

  /* ── 地图视野让位（自算 fit-box 的可见区边距，见 §5.4）── */
  --map-fit-gap: 24px;   /* 除档位 slotH 外，额外让出的呼吸边距 */
}

/* 深色：仅需补 --map-line-dim（其余 derive 自现有深色 Token） */
@media (prefers-color-scheme: dark) {
  :root {
    --map-line-dim: color-mix(in srgb, var(--border-2) 45%, var(--muted));
    --grab-color: var(--border-2);
    --grab-color-active: var(--fg-2);
  }
}
```

**搜索框淡出 + 底部让位（架构师拍板 §2.2/§2.3 配套）**

```css
/* ── 面板打开期间隐藏顶部搜索框（200ms 淡出 ⇒ 避免被面板裁剪、避免拖拽抖动）──
   口径：改目的地走「返回 → 半屏面板」路径，面板期间搜索框不可用。 */
.nav-searchbar { transition: opacity var(--sheet-dur-scrim) var(--ease-standard); }
body[data-sheet="open"] .nav-searchbar { opacity: 0; pointer-events: none; }

/* ── 正确性细节（架构师 R2 修正）：本项目是**应用壳**（面板 position:fixed，文档 body 不滚动）
   ⇒ padding 加在 body 上**无效**，必须加在**面板自己的滚动容器**上，
     否则面板列表底部被推出滚动区、不可达（真机验证清单必查）。 */
.route-sheet__body {                       /* ← 滚动容器，不是文档 body */
  overflow: auto;
  padding-bottom: calc(env(safe-area-inset-bottom, 0px) + var(--sheet-y-layout, 0px));
}
@media (prefers-reduced-motion: reduce) {
  .nav-searchbar { transition: none; }
}
```

**灰色线取值说明（为什么不用新硬编码色）**
- 现有 `--border-2` 太白（地图上会被当底图）、`--muted` 太深（会和彩色线争主角）；
- 取两者 `color-mix` 得中灰（浅色约 `#9FA5AE`，**仅为派生结果标注，非写入值**），正好是「同一条路、非乘车段」的灰；
- 用 `color-mix` 引用 Token ⇒ 满足「禁止硬编码颜色」，且深色自动派生。

## 3. 停靠点定义（三档 peek / half / full · 390×844 参考视口）

> R3：用户拍板补第三档 **peek（20% 收起档）** ⇒ 三档齐备。同一 sheet 实例，两态共用同一组档位。

**新增/更新 Token（§2 追加）**
```css
:root {
  --sheet-top-full: clamp(max(calc(var(--safe-top) + 44px), 12vh), 96px, 128px); /* ≈12vh */
  --sheet-top-half: 50vh;
  --sheet-top-peek: 80vh;   /* R3：20% 收起档（顶边 80vh ⇒ 可见高度 20vh） */
}
```

| 档位 | sheet 顶边 `--sheet-y` | sheet 高度 | 可见地图 | 默认状态 |
|---|---|---|---|---|
| **full** | `--sheet-top-full` `clamp(max(safe-top+44px,12vh),96px,128px)`（≈101–103px） | `100dvh − --sheet-y`（≈88vh） | 顶部 ~101–128px **可交互地图带**（搜索框已隐藏） | **推荐默认** |
| **half** | `--sheet-top-half` = `50vh` | `50vh`（≈422px） | 上半屏（≈422px）路线总览 | **详情默认** |
| **peek** | `--sheet-top-peek` = `80vh` | `20vh`（≈169px） | 顶部 80vh 地图 | 收起档（两态通用） |

**「顶部留一点点地图」的最终口径（已拍板）**
- 面板打开时**隐藏顶部搜索框**（200ms 淡出，见 §2），因此 full 档顶边直接取纯地图带；
- full 顶边 = `clamp(max(var(--safe-top) + 44px, 12vh), 96px, 128px)` ⇒ iPhone 17/18 实测 **约 101–103px 完整可交互地图带**（远大于"12px 缝"，满足「露出的地图可交互」）；
- 390×844 下 full ≈ **89dvh**，与 Google `0.90` 档手感一致；
- 注意：之所以不用 `safe-top + 76px`（旧的"搜索框底 + 12px"方案）：那会让露出地图只剩 12px，与需求矛盾 ⇒ **弃用**。

### 3.1 peek 档内容摘要（20vh ≈ 169px，可用内容区 ≈ 120px）

> 铁律：peek 只有 ~120px 内容区，**必须放"当下最有价值的一句话"**，不放列表、不放按钮组。两态摘要**结构相同**（OD 行 + 指标行），只换第二行的语义。

**通用骨架**（`grabber 24px` 之下，2 行）
```
┌───────────────────────────────────────┐
│                 ────                  │  ← 把手 36×4
│  擎天匯 → 澳門科技大學                 │  ← 行1：OD 单行截断（--text-sm / --muted）
│  最快 28 分  · [25路][3路]  共 3 條    │  ← 行2：大号指标 + 线路 chips
└───────────────────────────────────────┘
```

| 态 | 行1（OD） | 行2（摘要指标） |
|---|---|---|
| **推荐态 peek** | 起终点 OD（截断） | **最快时长（大字，--fw-announce）** + 最快方案的**线路 chips**（色块 = 线路色，数据驱动）+ `共 N 條`（--meta） |
| **详情态 peek** | 起终点 OD（截断） | **该卡时长（大字）** + `换乘 X 次`（如有）+ **线路 chips** + `HH:MM 抵达`（--meta） |

**视觉规格**
- 行 2 时长：`--text-2xl`（约 20px）/ `--fw-announce` / `--fg`；单位「分」用 `--text-sm`/`--muted`（数字与单位不同阶，层次更清）；
- 线路 chips：复用现有线路 chip（`--radius-chip` + 线路色/`--accent-soft`），高度 ≤20px，最多显 3 个 + `+N`；
- 行 1 OD：`--text-sm` `--muted`，单行 `text-overflow: ellipsis`；
- 右侧可选一个 **Tabler `IconChevronUp`（20px，`--muted`）** 作「上拖展开」的提示（非 emoji、非按钮）；
- 强调色（`--accent`）本屏 **≤2 处**（建议只用于线路 chips，或仅 OD 不额外着色）；
- 点整个 peek 区 = 回到该态默认档（推荐→full / 详情→half），与「上拖」等价（更方便单手）。

### 3.2 三档关闭链路（下拉到 peek 之后怎么办）

```
地图 ──(出发)──► 推荐[默认 full]
                     │ 点卡片
                     ▼
                  详情[默认 half]

推荐 full ↕ half ↕ peek ──(peek 再下拉)──► 关闭 → 回地图
详情 full ↕ half ↕ peek ──(peek 再下拉)──► 回推荐[默认 full]   ← 不是直接关地图
详情 关闭键/返回 ─────────────────────────► 回推荐[默认 full]
```

- **推荐态**：下层是地图 ⇒ `peek` 再下拉 = **关闭（回地图）**；
- **详情态**：下层是推荐 ⇒ `peek` 再下拉 = **回推荐（不是关地图）**（对齐 Google Maps：详情收起回上一层，不直接退出）；
- 详情另有**显式关闭键/返回**（`≥44×44`）→ 回推荐；键盘 `Esc` 同效；
- 关地图后 `--sheet-y` 复位为 `100dvh`（完全推出），下次打开回到该态默认档。

### 3.3 三档阈值与吸附边界（三档通用）

| 项 | 值 | 说明 |
|---|---|---|
| 换档判定 | **0.28 × 相邻档距（运行时 px）** 或 flick `|v| > 0.5px/ms` | **三档通用**，按**逐对**档距自适应 |
| 档距比例 | full↔half ≈ **38vh**；half↔peek ≈ **30vh** | 逐对、非等距 ⇒ **只存 vh 比例，px 运行时现算** |
| 换档阈值比例 | full↔half ≈ **10.64vh**；half↔peek ≈ **8.4vh** | = 0.28 × 档距比例 |
| 换档阈值（390×844 现算） | full↔half ≈ **90px**；half↔peek ≈ **71px** | 例：0.28×322px / 0.28×253px；**换屏即变** |
| 吸附 | 取「结束位置 + 速度投影」最近的**可用档** | 三档吸三者；不足 0.28×档距则弹回原档 |
| 上边界 | full 档继续上拉 → **硬停 full**（无更高档），可给轻微阻尼(≤12px) | 不越界 |
| 下边界 | peek 档继续下拉 > `--drag-close-dist`(96px) → **关闭/回退**（见 §3.2） | 越过最低档触发关闭 |
| 关闭速度判定 | flick `|v| > 0.5px/ms` 向下 且 位移 > 32px → 关闭 | 三档通用 |

- **阈值必须运行时计算**：`阈值Px = 0.28 × 相邻档位实际 px 间距`（由屏高把 `[full, 50vh, 80vh]` 换算后取差）。**不得把 90px/71px 当常量**（它们只是 390×844 的换算结果）；
- **逐对阈值示例**（390×844）：full→half 需拖 >`≈90px`；half→peek 需拖 >`≈71px`；
- 三档均支持**跳档**：快速 flick 可一次跨两档（速度投影落在目标档即吸附到目标档）。

**横向底导让位**：sheet 底边落在 `bottom: 0`，**不与 `.bottom-nav` 共存**——弹窗打开时底导已被 sheet 覆盖（z 层级见 §5）。地图容器恒 `fixed inset:0` 铺满，**被 sheet 覆盖而非被挤压** ⇒ 无 reflow、无地图重绘抖动。
- 注意（peek 特有）：`peek`（20vh）同样落在**屏幕最底部**，会**盖住底部导航**。这是"单实例、单向 transform"模型的必然结果，与 half/full 行为一致（任何开启面板都是聚焦态）。若产品要求 peek 时仍可见底部导航，需给 peek 单独让出 `tabbar-h + safe-bottom`（`--sheet-top-peek: calc(100dvh - <20vh> ...)`）——**列为可选，待产品定**。

**桌面 ≥1024px**：沿用现有 `.step-sheet` 桌面策略——sheet 改为**右上固定 420px 面板**（`top:96px; right:16px; bottom:16px; left:auto; translate:0`），地图铺满左侧；拖拽把手在桌面 `cursor:default`（用 Esc / 关闭键）；桌面**不做 peek 档**（面板常驻展开，`Esc` 关闭）。

## 4. 拖拽跟手规范（手感核心）

### 4.1 位移表达（最终口径）
- **只用 `transform: translateY()`**（GPU 合成层），**禁止**动画 `top / height / margin-top`（会 reflow → 掉帧）；
- sheet 元素结构（架构师 §2.3）：
  ```css
  .sheet {
    position: fixed; top: 0; left: 0; right: 0; height: 100dvh;
    transform: translateY(var(--sheet-y));       /* --sheet-y = 当前档位顶边 px */
    transition: transform var(--sheet-dur-settle) var(--sheet-ease);
    will-change: transform;
  }
  .sheet[data-dragging="on"] { transition: none; }  /* 拖动中 0ms 跟手 */
  ```
- **跟手增量是"叠加"不是"覆盖"**：拖动中 `translateY(calc(var(--sheet-y) + <dragDelta>))`（架构师明确）；
- 释放后：移除 `data-dragging`，回到 `translateY(var(--sheet-y))`（`--sheet-y` 更新为落定档）。

### 4.5 `--sheet-y` 双变量建议（正确性 + 性能·架构师已采纳并修正选择器）
面板底部内容让它可达，但若**拖动中每帧更新 padding ⇒ 每帧重排**，直接吃掉 60fps。故拆两个变量：

| 变量 | 更新时机 | 用途 | 是否触发重排 |
|---|---|---|---|
| `--sheet-y-anim` | 拖动中**每帧** | 只喂 `transform: translateY()` | 否（合成层） |
| `--sheet-y-layout` | 仅档位**落定（过渡结束）**时同步一次 | 喂**滚动容器** `padding-bottom` | 是，但只在档位切换（≤2 次/手势） |

```css
.sheet { transform: translateY(var(--sheet-y-anim)); }
/* R2 修正：本项目是应用壳（面板 position:fixed，文档 body 不滚动）
   ⇒ padding 加到 body 无效，必须加到**面板自己的滚动容器** */
.route-sheet__body {                                    /* ← 滚动容器，不是 body */
  overflow: auto;
  padding-bottom: calc(env(safe-area-inset-bottom, 0px) + var(--sheet-y-layout));
}
```
注意：真机验证清单必查：**档位落定后，面板列表底项可滚到底且可见**（不被底部导航/安全区吞掉）。

### 4.2 手势实现（低延迟）
- 用 **Pointer Events**（`pointerdown/move/up/cancel`）+ `setPointerCapture`，**不**用 touch/mouse 双绑；
- 拖动中 `pointermove` 里 `preventDefault()`，并 `touch-action: none`（把手区）；内容区 `touch-action: pan-y`；
- 方向锁：首次 `pointermove` 判定主轴——**垂直分量 > 水平分量**才劫持为 sheet 拖拽，否则放行给地图/内部滚动；
- **`will-change: transform` 仅在拖动期间挂上**，`pointerup` 后移除（常驻会吃显存）。

### 4.3 释放判定（三档通用）
> 档位 = [full, half, peek]；阈值为 **逐对** 计算（档距非等距），详见 §3.3。

| 手势 | 判定 | 结果 |
|---|---|---|
| 下拉位移 > 相邻档距 × `--drag-switch-ratio`(0.28) | 或速度 < `-0.5px/ms` | 降一档（可跨两档若 flick 投影落在目标档） |
| 上拉位移 > 相邻档距 × 0.28 | 或速度 > `+0.5px/ms` | 升一档 |
| 已在 **peek** 档，且下拉位移 > `--drag-close-dist`(96px) | 或速度 < `-0.5px/ms` 且位移 > 32px | **关闭**：推荐态→回地图；详情态→回推荐（见 §3.2） |
| full 档继续上拉 | — | 硬停 full（无更高档） |
| 未达阈值 | — | 弹回**最近档**（`--sheet-dur-settle` 260ms） |

### 4.4 视觉反馈（拖动中）
- 把手条 `--border-2` → `--grab-color-active (--muted)`（150ms，`--dur-fast`）；
- sheet 阴影**保持不变**（不做"越拖越大"的戏剧化，保持克制）；
- 由 peek 下拉逼近关闭阈值（60%）时可选轻振动 `navigator.vibrate(8)`（渐进增强，桌面忽略）；
- 拖动时 `user-select:none; -webkit-user-select:none`（防选中 OD 文案）。

## 5. 路线总览视觉规范

> 触发：点推荐卡片 → 详情弹窗进入「下半屏」，上半屏 = 路线总览。
> 口径（用户拍板）：**乘车区间彩色，区间外灰色；巴士图标保持现有样式不改。**

### 5.1 线的分层与色值

| 层 | 角色 | strokeColor | strokeWeight | opacity | amap zIndex |
|---|---|---|---|---|---|
| 底层 | **区间外**灰线（整条线路铺底） | `--map-line-dim`（≈#9FA5AE） | **6** | 0.85 | 68 |
| 上层 | **乘车区间**彩线（覆盖在灰线之上） | 线路色（`routes.color`，数据驱动） | **6** | 0.92 | 72 |

- **线宽统一 6px**（与现有 `strokeWeight: 6` 衔接，架构师已拍板 **6/6**，不做 4/6——避免上下车站处的粗细台阶）；层次**只靠颜色 + 透明度**区分；
- 灰线色值**运行时**用 `getComputedStyle` 读 `--border-2` 派生（画布绘制读不到 CSS 变量，同 maskFill 模式）；
- `lineJoin/lineCap: round`、`showDir: true` 全部沿用现有配置；
- **接缝**：彩线是灰线的真子集，上/下车站处两者端点共线 ⇒ **无断点、无重叠加深**（架构侧按站序切片，视觉侧只需保证同宽同 z 相邻）。

### 5.2 起终点标记（沿用现有 OD 语言，不新造）

| 标记 | 复用类 | 视觉 |
|---|---|---|
| 起点（上车站） | `.nav-map__originpin` | Ø18 圆 · `--brand-green` · 2.5px `#fff` 描边 |
| 终点（下车站/目的地） | `.nav-map__destpin` | 20×26 水滴 · `--error` · 1.5px `#fff` 描边 |
| 途经站点 | `.nav-map__station` / `--lrt` | 现有：巴士 Ø11 实心蓝圆 / 轻轨 13 方点（不动） |

- 上/下车站若无站点 marker，直接由 pin 表示；有则 pin 叠加在站点上方（z 110/120 > 站点 90/95）；
- `offset` 沿用现有（origin `-9,-9`；dest `-10,-20`），保证针尖对准真实坐标。

### 5.3 层叠关系（z-index 全景·已按架构师拍板更新）

| 层 | DOM | z-index | 内容 |
|---|---|---|---|
| 底图 | 高德 canvas | 0 | 瓦片 / 路网 |
| 遮罩（可选） | amap | 50 | 现有 mask（低于线） |
| 灰线段 | amap Polyline | 68 | 区间外 |
| 彩线段 | amap Polyline | 72 | 乘车区间 |
| 站点 marker | amap Marker | 90 / 95 | 巴士 / 轻轨 |
| 定位 & 起终点 | amap Marker | 110 / 120 | me / origin / dest |
| **车辆图标** | **amap Marker（原生化）** | **130** | 车辆已从 React 覆盖层改为原生 marker |
| 面板（推荐/详情） | React | 70 | 单一底面板 |
| 卡片浮层 | React | 90 | `.nav-card-overlay`（车卡/站卡） |

> **关键变更（务必落码）**：车辆图标本轮**从 DOM 覆盖层（z15）改为原生 amap marker**，进入高德内部命名空间。若不给高 `zIndex`，车会被站点(90/95)、pin(110/120) 压住 ⇒ **可见回归**。故车辆 marker **`zIndex: 130`（> pin 120）**。
> 注意：另：卡片层 90 > 面板层 70 ⇒ **打开卡片时必须先收起面板**，避免卡片浮在推荐/详情面板之上（同 Google Maps 语义）。

### 5.4 地图视野联动（让路线落在可见区中央）

> **注意（架构师纠正·必读）**：本项目在地图 `setLimitBounds(澳門)` 场景下，**不能用 `setBounds` / `setFitView`**（会被撑到珠海斗门、zoom 掉到最小；代码记录 `NavMap.tsx:580-593`）。
> ⇒ 取景改为**自算 fit-box**（见技术方案 §2.4）：`setZoomAndCenter(z, boxCenter, immediately=true)` + `panBy(0, innerHeight/2 − slotH/2)`，其中 `slotH` = 当前档**顶边以上**的可见高度（full≈12vh / half=50vh / peek=80vh），`z` 由外包框 + `slotH` 反推（复用 `NavMap.tsx:604-613` 自算）。

视觉等价目标（不依赖具体 API）：**让路线外接框在「档位顶边以上的可见区」居中**，即

```
可见区高度 slotH = 当前档顶边 y（full≈12vh / half=50vh / peek=80vh）
路线外接框 应在 slotH 区域内上下居中（左右居中）
```

- **detail half**：`slotH = 50vh` → 路线居中在上半屏；
- **detail full**：`slotH ≈ 12vh` 条以上区域 → 路线居中在顶部地图带下方；
- **detail peek**：`slotH = 80vh` → 路线几乎全屏居中（仅底部 20vh 被摘要遮住）；
- 档位切换时**只重算 fit-box**（不重画线、不重建地图、不调用 `setBounds`）；高德自带缓动与自定义过渡**不叠加**。

### 5.5 卡片浮层 `.nav-card-overlay`（车卡/站卡移出 wrap 后）

```css

  left: var(--space-4);   /* 16px，与搜索框/顶栏 chrome 同一水平基线（原 8px，统一） */
```

## 6. 过渡动画参数表

| 动作 | 时长 | 缓动 | 实现 |
|---|---|---|---|
| 打开推荐弹窗（底部滑入） | **260ms** (`--sheet-dur-settle`) | `--sheet-ease` | `translateY(100dvh) → translateY(--sheet-y)` |
| 推荐 → 详情（换层/换档） | **260ms** | `--sheet-ease` | 同 `translateY` |
| **三档换档**（释放归位，full/half/peek 通用） | **260ms** (`--sheet-dur-settle`) | `--sheet-ease` | `transform: translateY` |
| peek → 关闭/回退（下拉） | **260ms** | `--sheet-ease` | `translateY(80vh) → 100dvh` |
| peek 内容摘要显隐（随档位切换） | 200ms (`--sheet-dur-scrim`) | `--ease-standard` | `opacity`（避免列表→摘要跳变突兀） |
| 详情关闭 → 回推荐 | **260ms** | `--sheet-ease` | `translateY(--sheet-y) → 100dvh` |
| 下拉关闭 | **260ms** | `--sheet-ease` | 同上 |
| **拖动中** | **0ms** | — | `transition: none`（跟手） |
| 彩色区间线显隐 | 200ms (`--sheet-dur-scrim`) | `--ease-standard` | Polyline opacity 0↔0.92 |
| 把手颜色（拖动反馈） | 150ms (`--dur-fast`) | `--ease-standard` | background-color |
| **搜索框淡出/淡入（面板开合）** | **200ms** (`--sheet-dur-scrim`) | `--ease-standard` | `opacity`（`body[data-sheet=open]`） |

> `--sheet-ease = cubic-bezier(0.32, 0.72, 0, 1)`（架构师锁定，标准减速曲线）。控制点 y 值均 ≥0 且 ≤1 ⇒ **无 overshoot、非弹跳**，在红线内。
> **R4（时长统一）**：本仓实现用**单条** `transition: transform var(--sheet-dur-settle) var(--sheet-ease)`（`globals.css:5548`）覆盖**打开/换档/关闭** ⇒ 三者**统一 260ms**（原 300/240ms 作废；实现不改代码）。

**禁用清单（本轮硬约束）**
- 禁止（X）：`--spring-release cubic-bezier(0.22,1.9,0.36,1)`（overshoot 回弹，sheet 会"弹一下"）；
- 禁止（X）：任何 `cubic-bezier` 控制点**第二值 <0 或 >1**（会过冲）的曲线；
- 禁止（X）：>400ms 的过渡；禁止同时动画 >3 个元素；禁止动画 `top`（改用 `transform`）；
- 允许（OK）：`--sheet-ease (0.32,0.72,0,1)` 与 `--ease-standard (0.2,0,0,1)` 两条标准减速曲线。

**prefers-reduced-motion**：所有 sheet transition 置 `none`，档位**瞬切**（复用现有全局 `@media` 兜底 + 本节显式声明）。

## 8. 边界视觉

### 8.1 多段换乘路线总览
- **每段独立着色**：按 `card.segments` 逐段建 Polyline，段间**在换乘站自然相接**（不额外画灰线，灰线只表示"同线路非乘车段"）；
- **换乘接缝**由**换乘站点 marker 覆盖**（复用现有双色切分：`lrt-cut-half` 水平 / `lrt-cut-diag` 斜切），视觉上"线从站点穿出"；
- **步行段**（换乘步行）：**本轮 Backlog，不做**（架构师拍板：换乘节点双色环、步行虚线延后）。本轮换乘仅靠"逐段线路色 + 换乘站点 marker"表达。
- 详情卡顶部一行图例：复用 `.route-stack`（线路色块 + 线路名，斜切分隔），与地图颜色一一对应；
- 若某段无 shapes（数据缺）→ 该段**不画线**，仅保留站点 + 卡内文字提示（不画"断头线"）。

### 8.2 无实时车
- 地图上**不绘制任何车辆图标**（**不是**画灰车——灰车会和"信号丢失"状态混淆）；
- 路线总览**照常显示彩色乘车区间**（线路本身不因无实时车而变灰）；
- 详情卡对应线路行：文案"暂无实时车"，色用 `--muted`（与"推算值灰"语义一致，不新造色）；
- 可选：卡片顶部一条 `--warn-soft / --warn` 轻提示（复用 `.fav-note--warn`），说明"该线路暂无实时班次"。

### 8.3 超长环线（26 号）
- 环线 shapes 是**闭合环**：按实际乘车方向（`routeLine.dir`）把环切成"乘车弧"与"非乘车弧"；
- **彩弧 = 上车站 → 下车站沿行驶方向的那一段**；其余整环走灰线；
- **视野用彩弧包围盒**（而非全线包围盒）——否则整环取景会把地图拉太远，看不到区间细节；
- 若上/下车站几乎同点（环线短程绕行），彩弧可能覆盖大半环：此时**必须靠 `dir` 指定方向**，否则会画错方向；卡内以"绕行 N 站"文案说明；
- 起终点 pin 若几何重叠：利用**形状差异**区分（origin = 实心圆 / dest = 水滴形，已不同形），必要时 dest pin `offset` 再外移 4px。

### 8.4 其它边界
- **站名超长**：sheet 头部 OD 文案 `text-overflow: ellipsis` 单行截断（复用现有 `.result-sheet__od`）；
- **极短路线（单站）**：彩线段可能 <20px → 取景设**最小 zoom**（`zoom >= 15`），避免无限放大；
- **线路数据加载中**：先只显示灰线（整线）+ 顶部细进度条（复用 `.nav-result__progress`），彩线到位后 200ms 淡入，不阻塞 sheet 打开。

## 9. Agent 实现提示（给前端）

1. **组件挂载位置**：推荐/详情 sheet 必须挂在 `.nav-map-wrap` **之外**（wrap 是层叠上下文，挂进去会被底导压住 —— Spec AC-13 教训，现有注释已标）；
2. **z 层级**（已按架构师拍板）：面板层 **70** > 搜索层 60 > 站点卡 30 > 品牌栏 20；**卡片浮层 90**（打开卡片即收起面板）；车辆 = 原生 marker **zIndex 130**；
3. **单实例复用**：推荐与详情共用**一个 sheet 容器组件**，用 `data-sheet-state="recommend|detail"`（注意：**不是** `data-state`，后者被车辆图标占用）+ `data-detent="full|half|peek"` 切换；档位数组 `DETENTS = [--sheet-top-full, 50vh, 80vh]`，避免两套拖拽逻辑漂移；**6 枚契约观测钩子**见 `13-状态矩阵-20260923.md` §0；
4. **不重建地图**：档位切换只**重算 fit-box（§5.4）** / 切 Polyline 显隐，**不 unmount 地图实例**；
5. **CSS 变量落点**：§2 的 Token 追加到 `globals.css` 的 `:root`（深色 `@media` 块补 `--map-line-dim` / grabber 两项）；**新增 `--sheet-y-anim` / `--sheet-y-layout` 双变量**（§4.5）+ **`--sheet-top-peek: 80vh`**（R3）；
