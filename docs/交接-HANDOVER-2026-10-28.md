## 7. 硬规则（摘要 · 全文见 `.workbuddy/memory/MEMORY.md` 铁律 1~33）

1. **禁改 `.workbuddy/`**（未入 git）· 文件「失踪」先查 `D:\$Recycle.Bin\`
2. 改 `src/`/`scripts/`/`db/` 后必须 `tsc --noEmit` + `lint` + build exit=0
3. 📌 发版顺序：先 bump `package.json` 再 build · 本地 commit + **Vercel CLI 直发**（GitHub 封禁期）
4. 🚨「分析/盘点」默认**只口头报告**；要改文件先给选择题
5. 🚫 不用 `git checkout` 切分支（本机删除会重定向到回收站，整棵树消失）
6. 🚨 新 API 必须登记 `middleware.ts` 的 `PUBLIC_PREFIXES`（fail-closed）
7. ⚖️ 合规四红线：非商业 · 注明来源+取得日期 · 不改内容 · 派生值说明算法
8. 🔒 会改数据的 db 命令一律走 `npm run`（`scripts/db-guard.ts`）
