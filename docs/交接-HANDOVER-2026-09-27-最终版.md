## 5. 分桶方案（v3.5.5 终局 · 今日核心成果）

**查询口径**（用户查询时按「星期+时刻+节假日」选池）：

```
工作日 07-09 → am_work ｜ 09-16 → day ｜ 16-20 → pm ｜ 20-07 → night
周末/节假日 07-09 → am_weekend ｜ 其余全部 → all（全周池，不分段）
```

**聚合口径**（重建时）：am 分日型隔离；day/pm/night 含全部样本（周末稀释）；all 全量。
**判据**：「切段」只给「有形状」的群体——工作日四段形状各异（早 1.11/晚 1.08/夜 0.93）→ 切四段；周末 9 点后形状平坦 → 只切晨间。
**节假日**：`lrt_holidays` 表（澳门公众假期 2025-12~2027 · 已过官方 gov.mo 三源核对）→ 按周末同款。
**实现**：`buckets.ts`（`bucketOfRoute` 聚合 / `queryBucketOf` 查询 / `nowBucketOf`）、`holidays.ts`（`nowBucketOfHolidayAware` · 缓存 TTL 6h）。
**⚠️ 运维**：假期表需 2027 年内补 2028+；周六样本极少（「周末」结论实为周日）；建议每 ~20 轮重跑 `⑧` 系列 CV。

## 7. 铁律速查（违反会出事故）

1. **发布**：bump `package.json` → tsc/lint/build 三绿 → 本地 commit → Vercel CLI 直发；**GitHub 暂停期不碰远程**（push 后补）
2. **`npx` 可能静默失效** → node 直调 CLI 实体；构建走 **PowerShell 通道**（Bash 沙箱 EPERM）
3. **删除=进回收站**（`git checkout` 是元凶——别用它切分支）；文件「失踪」先查 `D:\$Recycle.Bin\`
4. 改 `.json` 用编辑器工具（禁 PS `Set-Content`——BOM 会炸 build）
5. **会改数据的 db 命令走 `npm run`**（生产库守卫 `--allow-prod`）；分析「盘点」类请求默认只报告
6. **UA 自报身份冻结**（`MUSTDengxiao` + `personal non-commercial`）；DSAT 调用 purpose 需避开熔断判定
7. 所有对用户的提问用**选择题 + 通俗完整句**（默认 `AskUserQuestion`）；**破坏性操作先确认**
8. 交付前「实连实跑」验证——「值填进文件」≠「能用」；断言禁硬编码
9. `.workbuddy/` 永不删除；称谓：对话「主人」/ 文档代码一律中性
