屏 05 定稿 · 段内插值用户点（youAt.afterIdx / frac） 删除「您在这里」整行（Spec §7）。用户点统一由 youAt = { afterIdx, frac } 驱动、不占行： frac = 0 ⇒ 落在 afterIdx 节点上（= 停靠中，节点本身变用户点）； 0 < frac < 1 ⇒ 骑在 afterIdx 与 nextIdx 之间的纵线上，位置 = 段内插值。
