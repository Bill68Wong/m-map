## 10 项需求（用户原文摘要）

1. 弹窗操作时地图抖动 + 自动刷新导致比例尺归位（学习谷歌地图稳定体验）
2. 路线查看/导航模式：非本线站点隐藏（仅显示选中线路站点；换乘可多条）
3. 导航界面：窗格乱跑位 / 顶部灰框 / 线路标签总览移到总用时同行右侧 / 去掉"估算" / 车辆信息不重复显示下一站 / 下车横幅简化（站号+站名保持）
4. 线路标签统一圆角（或带白色斜间隙）
5. 用户位置标点：只留一个蓝点（呼吸、无"您"字、随移动、乘车沿线推进、经过变灰）；纵轴去"您在这里"、进站节点变用户点
6. 导航中只显示当前乘坐班车图标 + 修复图标不更新 + 点击车/站图标不再中断导航
7. 换乘用时：能赶上判定 + 等待计入总时长（修正换乘偏乐观）
8. 用户偏好模型（少换乘/少步行）+ 默认综合推荐模型（参数化）
9. 下车全自动 + 上车判定灵敏度优化
10. 去除高德底图自带站点标识（自定义地图样式）
