## 5. 缺陷清单

### 🔴 P0-γ（AC-121 门槛）· `FavoritesClient.tsx:287,307`
- **现象**：`npm run lint` = **2 error**（`react-hooks/rules-of-hooks`：`useMyLocation` cannot be called inside a callback）。
- **根因**：L145 `const useMyLocation = (which) => {...}` 实为**普通事件处理函数**（读 `userFix.fix` + 调 `userFix.start()`），却以 `use` 前缀命名 ⇒ ESLint 按 Hook 判。
- **影响**：**无运行时功能影响**（确为普通函数）；但违反 **AC-121（eslint 0 error，P0 门槛）** + 命名误导。
- **修法**：重命名 `useMyLocation` → `applyMyLocation`（同步 L287/L307）。

### 🟠 P1-ε（AC-113）· `globals.css:7264 .fav-flat__tool`
- **现象**：真浏览器 `getBoundingClientRect` → **w=44.0 h=30.0**（< 44×44）。
- **根因**：只设 `width:44px`、**未设 height**；卡 `min-height:56px`+`padding:12px 16px` ⇒ 工具高≈30。
- **影响**：「编辑起终点」与「⋯」两处触摸目标不足（AC-113 明列 44×44；Spec §8 通用红线）。
- **修法**：`.fav-flat__tool { height: 44px; }`。

### ℹ️ advisory（非阻断）
- **A-1（AC-105 夜）**：非营运时段 `lrtFirst` 仍置顶「次日首班」轻轨卡（因 `LrtLive.state` 在「当日有未来班次」时恒为 `running`，未区分「营运中」）。本地探针实测：`totalMin=397.7` 卡被置顶。建议加「营运中」判据。
- **A-2（AC-97/99）**：本地 00:05 轻轨收班（next 06:29）⇒ 轻轨构成无法成立，**需营运时段复验**（非缺陷）。
