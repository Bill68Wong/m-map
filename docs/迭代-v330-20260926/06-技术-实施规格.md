### 1.5 轻轨优先开关（AC-105）

- 新增 `src/lib/recommend/lrt-priority.ts`（纯函数）：
  ```ts
  import type { RankedItem } from "@/lib/nav/rank";
  export function applyLrtPriority(items: RankedItem[], limit: number, enabled: boolean): RankedItem[];
  ```
  - `!enabled` → 原样返回；`items.length` 不足则原样。
  - `baseline = max(totalMin of items.slice(0, limit))`；命中 = 含轻轨段（`rides.some(kind==='lrt')`，其建模已要求 `LrtLive.state==='running'` 且有可赶班次）**且** `totalMin <= baseline + 15`。
  - 命中者按 `totalMin` 升序**稳定置顶**；其余相对序不变；**只重排、不增删**；未命中**静默**。
- `src/lib/nav/nav-service.ts`：注入点 = `const ranked = rankItems(...)` **之后**、`ranked.slice(0, limit)` **之前**：`const ordered = applyLrtPriority(ranked, limit, lrtFirst); const cards = ordered.slice(0,limit)...`。
- `src/app/api/nav/route.ts`：新增可选参数 `lrtFirst`（`=1|true`）；非法回落 `false`（不 400）；透传 `planNav(input)` 的 `lrtFirst`。

  ② 无 v3：
     a. 若存在 v2('must.favorites.v2')：

     c. 均无：空 v3
