## 1. 产品定义

- 一句话：21 条功能调整 + 收藏体系重构（组合 + 地点两类）+ 三项 P0 修复（钉/路网超时/路由闸门）+ 轻轨体验细化（优先开关/方向/步行距离化/赶车提示）。
- 目标用户：作者本人（Android · Chrome 与微信双环境）。

## 2. 范围（锁定 · 24 交付项）

台账 21 条 + 石排灣路由漏洞 + 图标 3 项同源缺陷 + 观测补齐，全部为交付项。逐条对账以 `00-需求台账.md` 为唯一目录。

## 3. 明确不做

「本次暂无轻轨方案」提示（用户明确删）· 站条「（改乘）」小字 · 赶车提示进导航站条 · 地点卡「设为起点」快捷 · 新增设计 Token · 同 OD 强制合并（先只补 parallelRoutes，②Phase 2 评估）。

## 4. 关键契约（锁定）

| 契约 | 定案 |
|---|---|
| 高德 transit 超时 | `TRANSIT_TIMEOUT_MS = 4000` + `acquireWithWait(transit, 800ms)` + 保留一次重试 + 降级文案软化（ADR-103） |
| 钉渲染 | **内联 SVG**（两钉精确 SVG 按 02 附录；保留 `.nav-map__destpin/originpin` 类名、`offset(-10,-26)`、zIndex 110/120 不变）；CSS 去 background、filter 可选（ADR-102）。**起点 = 红色地图钉（`#B4342A`）——任何场景（含「起点 = 我的位置」）均以红钉承载起点语义，不得以蓝点替代**；蓝点仅表实时位置，两者可叠（红钉立于蓝点之上） |
| 钉诊断 | `?diag=pin` → `PinDiag` 浮层（两钉计数/rect/computed style/svg bbox/`data-nav-z`/`data-map`/环境）；生产默认不渲染 |
| altBuses | 本地补 `parallelRoutes` + **生成必须覆盖组合内每条线** + `backfillAltBuses` 幂等（空池/换乘仅首段口径） |
| 覆盖度闸门 | ① `ourDataCoverage` 口径修正（LRT 等待计入/分母改「本可由我们数据覆盖的时段」/步行按来源计入）② **轻轨方案豁免闸门 3** ③闸门 dropped 并入 `stats`（ADR-105） |
| 轻轨优先 | `/api/nav` +`lrtFirst=1`；注入点 = `rankItems` 之后、`slice(limit)` 之前；阈值 = **前 limit 张最慢 totalMin + 15min**；营运 = `LrtLive.state==='running'`；只重排不增删；未触发**静默** |
| 步行距离化 | `LRT_STATION_WALK` 常量（进/出站 **168m** · 協和换乘 **336m** · 蓮花换乘 **420m**）；分钟 = 距离÷84，读端按速度档缩放（禁双重缩档）；预留表化接口 |
| 赶车提示 | **复用 `TierBadge`**（`RoutePieces.tsx:27` · `TIER_TEXT` 五档文案 · `.rc-tier--1..5`）· 合并式（时刻文案进 `tierText`）· 触发 = `pickCatchTier`（正常档 null 且档 1/2 可行）· 保守措辞（禁「一定」）· 只在方案卡 |
| FAB | 首页（`off`）= 品牌栏右列原位；`data-nav-phase != off` = 右下浮动避让（bottom 公式复用 `--sheet-y-anim`） |
| 定位点击 | 立刻聚焦「最近一次已知位置」+ 恢复跟随；冷启动无缓存给加载态 |
| 多线标签 | 顶部总览栏 = `segments` 结构（与 `RecommendCard:112/184` 逐字同构，含 parallelRoutes）；站条上车站 = 实际可乘班车（四规则：主干能赶→主干；赶不上→altBuses 最早可赶并行线；无法判定→回落主干；**数据缺失不得显错线**） |
| 轻轨方向 | 格式 `{終點}方向`；推荐卡副行 + 站条 `.navstrip__dir`（两处现均为 `null` 硬传，须接通 `live.ts` 已有数据） |
| 图标 | help = **`book`/`bookFilled`**；顺修 `info-circle`（安全级）/`records`/`list`（零长度段+butt cap 同源）；`.verify/audit-icon-dots.mjs` 纳入门禁 |
| 收藏 v3 | `must.favorites.v3` = `ComboV3`（OD）+ `PlaceV3`（单点）；方案层/流程图编辑/预置全退役；迁移 = **导出 JSON + 隐藏备份键双层备份 → 删预设**（v1/v2 键保留可回滚）；**绝不删用户自建** |
| 收藏交互 | 点组合 = 首页式实时规划（复用 `/?query`，不新增路由）；点地点 = 首页式选点（目的地已设、不自动规划）；「收藏地点」入口 = 搜索框右上角原「已选」位（确认选点后出现）；「收藏组合」按钮两处同一常量；导航弹窗删收藏键（`NavDetailBody:104-116`） |
| 空态 | 删「仅有 X 条路线可用」→ 中性空态（`route-2` 图标 + 「暂时没有可用方案」+ 重试；无红色）；与错误态（路网文案保留）严格区分 |

## 8. 边界与约束

- 真机第一验收环境 = **Android**（Chrome + 微信）；钉修复必须双环境截图取证。
- 收藏迁移 = **不可逆操作前必双层备份**；任何情况不删用户自建组合/地点。
- 赶车提示 = 保守措辞、方案卡内、不弹窗、不改卡序（复用 `TierBadge` 胶囊承载 ⇒ **无独立 `role`**；胶囊为纯展示文本，随卡片 DOM 天然可读）。
- 轻轨优先 = fail-safe（不确定不置顶；只重排不增删）。
