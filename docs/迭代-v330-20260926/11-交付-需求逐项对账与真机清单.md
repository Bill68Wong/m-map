## 三、真机复验清单（请主人逐条测 · 重点已加粗）

### A. 地图钉（**最优先**）

1. **手机 Chrome + 微信各打开一次**：选起点/终点 → 看**红钉（起点）/绿钉（终点）**&#x662F;否显示（选点 → 选路线 → 导航全程）；
2. **若仍不可见**：URL 后加 **`?diag=pin`**（如 `musttoukou.vercel.app/?diag=pin`）→ 页面会显示诊断浮层 → **截图发我**（一次定位根因）。

### B. 导航与定位

1. **定位按钮**：点一下应**立刻**聚焦到你的位置（不等转圈）；
2. **FAB 两模式**：首页默认时在**右侧栏原位**（不与 M Map 标重叠）；打开路线面板后**浮到右下**并随面板上下移动；
3. **多线标签**：顶部总览 = 推荐时的组合（如 25/26）；站条上车站旁 = 实际能坐上的那班；
4. **轻轨方向**：轻轨方案应显示「氹仔碼頭方向」之类；
5. **轻轨优先**：偏好右侧开关；白天开它 → 若轻轨方案够快（≤最慢+15 分）会置顶+角标；**深夜开它 → 无变化**（静默，这是正确的）。

### C. 收藏（今晚迁移后）

1. 打开收藏页：应看到「收藏」底导名 + **组合在上 / 地点在下** + 扁卡片；
2. 点组合卡右侧「编辑」→ 可**改起点/终点**（跳搜索重选）→ 保存只改这一条；
3. 搜索目的地选中后 → 搜索框右上角出现「**收藏地点**」；
4. 点一条组合 → 应进入**和首页一样的规划界面**（有地图 + 推荐弹窗）。

### D. 石排灣→科大（**白天测**，轻轨营运时段）

1. 规划「石排灣 → 科大」：应出现「**石排灣上车（石排湾线）→ 協和医院换乘（氹仔线）→ 科大**」的方案（此前只有「走路去協和」）。
