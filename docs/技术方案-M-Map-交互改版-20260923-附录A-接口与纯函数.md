## A.1 `POST /api/nav/detail-body` 返回体扩展：`legs[]`

### A.1.1 现状与目标

现状返回 `{ ok, strips, otherRoutes, foldLive, stationLabel }`（`src/app/api/nav/detail-body/route.ts:60-69`）。**新增 `legs`**，为「路线总览」提供逐段的**线路色 + 上下车坐标**。`card.rides` 不含坐标（`RideLegView` 仅 `board/alight` 站码，见 `src/lib/recommend/types.ts:436-502`），故必须服务端补。

### A.1.2 类型（TypeScript，前后端共同契约）

```ts
/** 路线总览的逐段几何锚点（与 card.rides 一一对应、同序） */
export interface OverviewLeg {
  /** 段索引 = card.rides 下标（客户端据此与 card 对齐，勿依赖数组顺序） */
  index: number;
  route: string;
  kind: "bus" | "lrt";
  /** 线路主题色（routes.color）；缺省 null → 客户端回落 var(--accent) */
  color: string | null;
  /** 上车站（GCJ-02）；解析失败 = null（客户端降级，不阻塞） */
  board: { code: string; lng: number; lat: number } | null;
  /** 下车站（GCJ-02）；同上 */
  alight: { code: string; lng: number; lat: number } | null;
}

interface DetailBodyResponse {
  ok: true;
  strips: SegmentStrip[];          // 不变
  otherRoutes: string[];           // 不变
  foldLive: Record<string, string>;// 不变
  stationLabel: string | null;     // 不变
  legs: OverviewLeg[];             // ★ 新增
}
```

### A.1.4 服务端实现细则（`src/app/api/nav/detail-body/route.ts`）

1. **收集** 全部 `card.rides` 的 `route`（去重）与 `board/alight` 主码（去重）：
   - 站码归一到**主码**：`mainCodeOf(code)`（`@/lib/recommend/segment-lookup`，与 `/api/stations` 同口径 `station-code` 去 `/<平台>`）。
2. **两条批量查询并行**（`Promise.all`，**绝不进循环** —— 防 N+1）：
   ```sql
   -- ① 站坐标（WGS84；取主码，容忍平台后缀）
   SELECT code, lat, lng FROM stations
    WHERE lat IS NOT NULL AND lng IS NOT NULL
      AND (code = ANY($1::text[]) OR regexp_replace(code, '/\d+$', '') = ANY($1::text[]));
   -- ② 线路色（数据；勿硬编码）
   SELECT code, color FROM routes WHERE code = ANY($2::text[]);
   ```
   两条各自 `try/catch`：**色查询失败 → 该段 color=null（客户端回落）**；**站查询失败 → 所有 board/alight=null（整体降级，不 500）**（对齐本项目「降级不阻塞」铁律）。
3. **坐标转换**：`const gcj = wgs84ToGcj02({ lat, lng })`（`@/lib/amap/coord`，与 `/api/stations`、`/api/route-vehicles` 同源）。输出 `{ code: 主码, lng: gcj.lng, lat: gcj.lat }`。
4. 主码 → 坐标：`Map<mainCode, {lng,lat}>` 内存索引（`code` 去后缀归主码，保留首个非空）。
5. 组装 `legs`：`card.rides.map((r,i) => ({ index:i, route:r.route, kind:r.kind, color: colorMap.get(r.route) ?? null, board: coord.get(mainCodeOf(r.board)) ?? null, alight: coord.get(mainCodeOf(r.alight)) ?? null }))`。
6. 输入校验（不变）：沿用现有 `card.rides` 浅校验（`route/board/alight` 为字符串）。
7. 缓存头：`cache-control: no-store`（不变）。

> 兼容性：`legs` 为**新增字段**，老前端忽略即可；不改动既有字段 ⇒ 无破坏性变更。
> 白名单：`/api/nav` 前缀已覆盖（`middleware.ts:44`），**无需改中间件**。

## A.2 `src/lib/nav/route-overview.ts` 纯函数签名（新增）

**约束**：client-safe、**不 import pg**（前端组件直接引用）、纯函数、可单测。

```ts
/** [lng, lat]（GCJ-02） */
export type LL = [number, number];

export interface OverviewLegInput {
  index: number;
  route: string;
  kind: "bus" | "lrt";
  color: string | null;
  board: { code: string; lng: number; lat: number } | null;
  alight: { code: string; lng: number; lat: number } | null;
}

/** /api/route-shapes 的 shapes[] 元素（子集） */
export interface RouteShapeLite {
  dir?: string;                 // dsat_dir
  polyline: string;             // "lng,lat;lng,lat;..."
  startStop?: string | null;
  endStop?: string | null;
}

export interface ColoredLeg {
  index: number;
  route: string;
  kind: "bus" | "lrt";
  color: string | null;
  dir: string | null;           // 选中方向（供 /api/route-vehicles?dir= 用）
  gray: LL[];                   // 所选方向整条线（灰底线，zIndex 68）
  colored: LL[];                // board→alight 乘车区间（彩段，zIndex 72）
  degraded: boolean;            // true = 未切割成功 ⇒ colored === gray（整线着色）
}

/** 常量（集中导出，便于测试与调参） */
export const TOL_M = 80;              // 站到线最近点容差（超差视为该方向不含此站）
export const LOOP_EPS_M = 25;         // 首尾闭合判定（环线）
export const BOARD_EQ_ALIGHT_M = 50;  // 起终点同站阈值（整线着色）
export const DECIMATE_STEP_M = 15;    // 灰底线抽稀步长（可选）

/* ── 基础几何 ── */
export function parsePolyline(s: string): LL[];
export function distM(a: LL, b: LL): number;                 // 等距近似：dLat*111320, dLng*111320*cos(lat)
export function cumDistM(pts: LL[]): number[];
export function nearestOnPath(pts: LL[], p: { lng: number; lat: number }): { idx: number; distM: number };
export function isLoop(pts: LL[], startStop?: string | null, endStop?: string | null): boolean;

/* ── 核心 ── */
/** 选方向：对每个 shape 求 board/alight 最近点；剔除任一超 TOL 者；取 dBoard+dAlight 最小；并列取正向（iBoard<iAlight 或环绕正向） */
export function chooseShape(
  shapes: RouteShapeLite[],
  board: { lng: number; lat: number },
  alight: { lng: number; lat: number },
  tolM?: number,
): { shape: RouteShapeLite; dir: string | null; iBoard: number; iAlight: number; dBoard: number; dAlight: number } | null;

/** 切彩段：非环线 slice(iBoard, iAlight+1)（iBoard>iAlight → null）；环线 iAlight<iBoard 时环绕 slice(iBoard).concat(slice(0, iAlight+1)) */
export function cutColored(pts: LL[], iBoard: number, iAlight: number, loop: boolean): LL[] | null;

/** 组装全部乘车段（多段换乘逐段处理）；任一条件不满足 → 该段 degraded=true、colored=gray */
export function buildColoredLegs(
  legs: OverviewLegInput[],
  shapesByRoute: Record<string, RouteShapeLite[]>,
  opts?: { tolM?: number; boardEqAlightM?: number },
): ColoredLeg[];

/** 并集外包框（取景用；含起终点） */
export function unionBox(
  pathSets: LL[][],
  extra?: { lng: number; lat: number }[],
): { minLng: number; minLat: number; maxLng: number; maxLat: number } | null;

/** 灰底线抽稀（保首尾；相邻顶点 < minStepM 的中间点丢弃） */
export function decimate(pts: LL[], minStepM?: number): LL[];
```

### A.2.1 `buildColoredLegs` 行为规格（决策表）

| 输入情形 | 输出 |
|----------|------|
| `board`/`alight` 任一为 null | 该段 `degraded=true`，`colored=gray=所选方向整线`（无方向信息时取第一个 shape） |
| `shapesByRoute[route]` 缺失/空 | 同上（`gray=[]`，`colored=[]`，`degraded=true`） |
| `chooseShape` 返回 null（两方向都超 TOL） | 该段 `degraded=true`，`gray=第一个 shape 的整线`，`colored=gray` |
| 正常（非环线） | `gray=所选方向整线`，`colored=slice(ib, ia+1)` |
| 环线 + `iAlight<iBoard` | `colored = slice(iBoard) ++ slice(0, iAlight+1)`（环绕） |
| `distM(board, alight) <= BOARD_EQ_ALIGHT_M` | `colored=gray`（整线着色；PM 边界 #4） |
| 轻轨段（kind='lrt'） | 同巴士（轻轨亦有 `route_shapes`；无则降级） |

### A.2.2 与取景/车辆的衔接

- 取景外包框：`unionBox(legs.map(l => l.colored), [originPoint, destPoint])` → 交给 `NavMap` 的 `view.mode='fit-box'`（`slotTopPx` = 当前档顶边）。
- 车辆：仅对 `kind==='bus'` 的段，用 `leg.dir` 拉 `GET /api/route-vehicles?code=<route>&dir=<dir>&kind=bus`；轻轨段跳过。

## A.3 对拍脚本（`scripts/test-route-overview.ts`，新增）

新增 npm 脚本：`"test:overview": "tsx scripts/test-route-overview.ts"`（与既有 `test:dsat` 同型，纯函数无需 db-guard）。

**用例（断言即回归）**：

1. `parsePolyline("113.5,22.1;113.6,22.2")` → 2 点，数值正确；非法段被过滤。
2. `nearestOnPath` — 构造已知折线，点落在第 3 顶点附近 → `idx===2`。
3. `cutColored` 非环线正向 → `slice(ib, ia+1)`。
4. `cutColored` 非环线 `ib>ia` → `null`。
5. **环线环绕**：构造首尾闭合折线（模拟 26 号线，`board` 靠尾、`alight` 靠首）→ `colored` 长度 = `(n-ib)+(ia+1)`，且 `colored[0]≈board`、`colored.at(-1)≈alight`。
6. `chooseShape`：两方向折线，其一 board/alight 顺序反 → 选中顺序正的那个；两方向都超 `TOL_M` → `null`。
7. `buildColoredLegs` 降级：`shapesByRoute` 缺该 route → `degraded=true` 且 `colored===gray`。
8. `distM(board,alight)<=50` → 整线着色（`colored===gray`）。
9. **真实数据对拍（可选，连库）**：从 `route_shapes` 取 `26`（环线）与 `51A` 两方向真实 polyline + 一条真实卡（`strips`/`rides` 的 board/alight），断言 `colored.length <= gray.length` 且 `colored` 两端点分别接近 board/alight（< TOL_M）。

**探针脚本同批改法**（`scripts/probe-render.ts`）：
- 删除 `/nav`（136-143 行区）与 `/nav/detail`（143-149 行区）两段访问（页面将删，见主文档 §5.6）。
- 若要保留「详情渲染」探针 → 改为断言首页弹窗：`/?<query>` 打开后 `[data-sheet-state="detail"]` 出现、`data-overview-legs` > 0（新增观测钩子，见下）。

**新增观测钩子（自动化验收）**：面板 `data-sheet-state="recommend|detail"`、`data-detent="full|half|peek"`；总览容器 `data-overview-legs="<n>"`。
