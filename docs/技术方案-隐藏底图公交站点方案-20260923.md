# 技术方案 · 隐藏高德底图自带公交站点图标（MUST登校 / M Map）

> 角色：首席架构师 高见远　｜　日期：2026-09-23
> 用户决裁：**隐藏高德底图自带的公交站点图标**（「高德 API 地图不返回巴士站点，因为我们自己已经做了标点」）；**其余底图元素（道路、其他 POI、商户）保持不变**。
> 结论性质：可执行方案 + 用户操作教程 + 代码接线点 + 风险。版本锚定：高德 JS API 2.0。

---

## 0. 结论速览

| 路径 | 能否满足「只去公交站、其余不变」 | 结论 |
|------|-------------------------------|------|
| **A. 自定义地图样式（控制台手点一次）** | **能** | ✅ **推荐**。关闭「公交站点」要素后发布，代码 `mapStyle: 'amap://styles/<样式ID>'` |
| B. 用 key 直接创建/更新样式的 HTTP API | — | ❌ **不存在**官方接口（已检索确认）；样式只能在控制台创建/编辑/发布 |
| C. `setFeatures(['bg','road','building'])` 去 `point` | **不能**（连商户等所有 POI 一起关） | ⚠️ 仅备选，需用户接受「关掉全部 POI」 |
| D. 官方模板 / `showLabel:false` / 内联 `styleJson` | **不能** | ❌ 官方模板无「无 POI」变体；`showLabel` 会连街道名一起关；JS API 2.0 **不支持**内联 styleJson（见 §5 幻觉接口警告） |

**一句话**：唯一能精确达成用户要求的是 **路径 A**：在控制台**一次性**创建一个「关掉公交站点」的自定义样式，拿到样式 ID，在代码里以环境变量注入。免费版**允许创建 1 份自定义样式**（正好够用）。

## 1. 现状与目标

- 现状（读码）：`src/components/nav/NavMap.tsx:347` `new AMap.Map(canvasRef.current, {...})` **未传 `mapStyle`** ⇒ 使用高德**默认标准样式**；用户看到的公交站图标 = 底图 `point` 要素里的「公交站点」。
- 目标：仅隐藏该类目录标，其余（道路/其他 POI/商户/文字）**全部保留**。
- 约束：本项目已有自己的站点图层（`AMap.Marker`，`NavMap.tsx:740`），与底图 POI **互不影响**；隐藏底图公交站**不会**影响我们的标点。

## 2. 路径 A（推荐）：自定义地图样式

### 2.1 原理

高德「自定义地图（样式）」= 官方矢量底图的**样式层**。编辑器可对底图各类元素做**显隐 + 配色**，发布后得到一个**样式 ID**；代码用 `amap://styles/<样式ID>` 即可让整张底图按该样式渲染 ⇒ 只关「公交站点」、其余保持默认样式不动。

### 2.2 给用户的逐步操作教程（控制台，一次性，约 5–10 分钟）

1. 浏览器打开高德开放平台并**登录**：`https://lbs.amap.com/`（须与申请 `AMAP_JS_KEY` 的**同一开发者账号**）。
2. 进入自定义地图平台，二选一：
   - 官网导航「开发支持 → 自定义地图」；或
   - 直达 **GeoHUB 自定义地图控制台**：`https://geohub.amap.com/mapstyle/index`（样式编辑器 `https://mapstyle.amap.com/`）。
3. 点击「**创建地图样式**」（或「新建样式」）→ 选一个**基础模板**（选「标准」最接近默认底图）→ 点「创建」。
4. 进入样式编辑界面：左侧是**元素列表**（区域面 / 道路 / 文字标注 / 楼块 / 环境 / 交通设施 / 公共设施 / 地铁设施 / 商业场所 …）。
   - 找到与**公交站点**对应的元素（通常在「**交通设施 / 交通枢纽 / 公共设施**」一类下；名称可能是「公交站点 / 公交」）。
   - **取消它的可见性勾选**（编辑器对每个元素支持「显示/隐藏」+「改色」）。
   - ⚠️ **不要动**道路、其他 POI、商户、文字标注 —— 保持默认（这是「其余不变」的关键）。
5. 右上角「**保存**」→ 然后「**发布**」。
   - 发布生效约 **1 分钟**。
6. 进入「**使用与分享**」→ **复制样式 ID**（形如 `fdb98ba86eaa2e61e2b4c054ebe4989d`）。
7. 把该 ID 交给我们配置到环境变量（见 §2.3）。

> 免费版限制：**自定义地图样式创建数量 = 1 份**（付费版 20/30 份）。我们只需 1 份 ⇒ 免费版够用。
> 关键前置：**样式 ID 与 Key 必须同属一个开发者账号**，否则不生效。

### 2.3 代码接线点（架构侧，明确到行）

1. 环境变量（`.env` / `.env.local` / Vercel 环境变量）新增：
   ```
   AMAP_MAP_STYLE_ID=<第 6 步复制到的样式 ID>
   ```
   （与既有 `AMAP_JS_KEY` 同处；`.env.example` 同步补一行注释。）
2. 服务端读取（`src/app/page.tsx`，与 `jsKey` 同款，`page.tsx:45` 附近）：
   ```ts
   const jsKey = (process.env.AMAP_JS_KEY ?? "").trim();
   const mapStyleId = (process.env.AMAP_MAP_STYLE_ID ?? "").trim();   // ★ 新增
   ```
   经 `NavShell`（`src/components/nav/NavShell.tsx`）以新 prop `mapStyleId` 透传给 `NavMap`。
3. `NavMap` 初始化接线（**`src/components/nav/NavMap.tsx:347`** 的 `new AMap.Map(canvasRef.current, {...})`）新增一行：
   ```ts
   const map = new AMap.Map(canvasRef.current, {
     zoom: INIT_ZOOM,
     center: [MACAU_CENTER.lng, MACAU_CENTER.lat],
     viewMode: "2D",
     // ★ 隐藏底图公交站点：走自定义样式；未配置则用默认样式（不影响任何其他功能）
     ...(mapStyleId ? { mapStyle: `amap://styles/${mapStyleId}` } : {}),
     resizeEnable: true,
     /* ...其余不变... */
   });
   ```
   - 也可在就绪后用 `map.setMapStyle(\`amap://styles/${mapStyleId}\`)` 切换；但**初始化时传更省一次重绘**，且避免首帧闪默认样式。
   - `NavMapProps` 增可选 `mapStyleId?: string`；未配置时行为**与现状逐字节一致**（降级安全）。
4. 安全代理：样式瓦片经高德服务器按 JS Key 加载，现有 `window._AMapSecurityConfig.serviceHost = /_AMapService` 代理**不受影响**（代理只作用于服务类请求），**无需改中间件**。

### 2.4 路径 A 的风险 / 待核实

- **R1（待用户核实，关键）**：样式编辑器对「公交站点」的**粒度**。官方口径是「7 大类、百余种元素可配置」，理论上可细到「公交站点」；但**编辑器实际元素树我未能在线抓取到**（编辑器为 SPA，官方介绍页 404）。⇒ 用户在编辑器里**必须实测**：关掉公交站点后，**其他 POI/商户仍在**。若编辑器只能粗粒度开关「全部 POI」⇒ 路径 A 无法满足「其余不变」，需回退到 C 或请用户取舍。
- **R2**：样式生效约 1 分钟；发布前的旧样式缓存可能短暂存在。
- **R3**：样式走「单账号绑定」，后续换 Key/账号需同步维护样式归属。
- **R4**：免费版仅 1 份样式；若未来要第二套（如夜间样式），需付费升级。**建议把这份样式的用途写明**（勿拿去做别的实验，免得额度被占）。
- **R5**：隐藏公交站点**不影响**我们自己的站点图层（独立 marker 层）。

## 3. 路径 B（评估结论：不可行）

- 检索结论：高德**未提供**「用 Key 通过 HTTP 创建/更新/发布自定义地图样式」的公开 API。自定义样式的**创建/编辑/发布只能在控制台（GeoHUB / mapstyle）完成**。
- ⇒ 无法「在代码里一次性把样式建好」。**必须由用户手点一次**（§2.2），之后由代码长期使用样式 ID。
- （备查）移动端 SDK 另有「离线样式文件」下载（`CustomMapStyleOptions`），与 Web 无关，不适用。

## 4. 路径 C（备选）：`setFeatures` 去 POI

```ts
map.setFeatures(["bg", "road", "building"]);   // 去 point
```
- 效果：隐藏**所有 `point`（POI 点，含公交站/地铁站/餐饮/商场…）**及其标注。
- **与用户「其余不变」冲突** ⇒ 仅当用户接受「连其他 POI 一起关」时才用。
- 优点：零控制台操作、代码一行、可随时开关。缺点：过度隐藏。

---

## 5. 路径 D（不可行）与「幻觉接口」警告

- **官方样式模板**（normal / dark / light / whitesmoke / fresh / grey / blue_night / macaron…）**没有**「无 POI / 无公交站」变体。
- `showLabel:false`：隐藏**全部文字标注**（含街道名、地名），过度。
- ⚠️ **以下 API 在官方 JS API 2.0 文档中不存在，属错误/幻觉写法，严禁使用**：
  - `map.setMapStyle({ styleJson: [ { featureType, elementType, stylers:{visibility:'off'} } ] })`（该写法来自非官方/AI 生成文章，**不是**高德接口）；
  - `map.setFeatures(['bg','road','point:none','text:none'])`（官方 `setFeatures` **只接受** `'bg' | 'point' | 'road' | 'building'`，**没有** `:none` 后缀、**没有** `text` 项）；
  - `AMap.createStyleEditor()`（官方参考手册**未收录**；检索仅见 AI 生成站点提及）。
  - 依据：官方《自定义地图》教程与《参考手册 · 地图》`setMapStyle(style:String)` / `setFeatures(feature:Array)`。

---

## 6. 验收步骤（落地后）

1. 配置 `AMAP_MAP_STYLE_ID` 后进首页 → 放大到公交站密集区（zoom ≥ 15）。
2. 断言 **底图不再出现公交站图标**；**道路、其他 POI（商户/餐饮）、文字标注仍在**。
3. 断言 **我们自己的站点图层正常**（`data-station-count > 0`），点击站点出的信息卡正常。
4. 未配置 `AMAP_MAP_STYLE_ID` 时（本地/回滚）→ 底图回到**默认样式**，其余功能不受影响（降级安全）。
5. 观感回归：底图配色与默认一致（因基于「标准」模板、只调显隐）。

---

## 7. 推荐落地顺序

1. **用户** 按 §2.2 在控制台创建并发布「关公交站」样式，取回样式 ID。
2. **架构/开发** 按 §2.3 接线（env → page → NavShell → NavMap 一行），走 §6 验收。
3. 若用户实测发现编辑器无法只关公交站（R1）⇒ 回退路径 C，并就「是否接受连其他 POI 一起隐藏」请用户拍板。
